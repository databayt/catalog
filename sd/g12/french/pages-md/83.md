**L'enchaînement vocalique**

C'est la prononciation de deux voyelles qui se suivent ou d'une voyelle suivie d'un H aspiré dans un mot ou dans deux mots qui se suivent.
Rappel : on ne fait pas la liaison avec le H aspiré.

Tahiti / Téhéran / Sahara / Aéroport / Cacao / Pharaon / Saïd / Caïd / Maïs / Naïf
Créer / Haïr / Trahir / Théâtre / Lycéen / Européen / Saoudien
