On peut transformer un nom masculin en féminin, en général en ajoutant un e au masculin

| Nom masculin | Nom féminin |
|---|---|
| se termine par e | même forme |
| *secrétaire, journaliste, pompiste, ministre, pédiatre* | |
| se termine par une consonne | on ajoute un -e |
| *avocat, magistrat* | *avocate, magistrate* |
| | on double la consonne finale du masculin et on ajoute un -e<br>-ien > -ienne<br>-at > -atte |
| *pharmacien, comédien, informaticien, mécanicien,*<br>*chat* | *pharmacienne, comédienne, informaticienne, mécanicienne*<br>*chatte* |
| se termine par -er ou -ier | on ajoute un -e et un accent grave<br>-er > -ère<br>-ier > -ière |
| *boulanger, boucher, infirmier* | *boulangère, bouchère, infirmière* |
| se termine par -eur | -eur > -euse |
| *danseur, contrôleur, chanteur* | *danseuse, contrôleuse, chanteuse* |
| se termine par -teur | -teur > -trice |
| *acteur, facteur, instituteur, agriculteur* | *actrice, factrice, institutrice, agricultrice* |
| se termine par -eur | -eur ne change pas ou on ajoute un e |
| *professeur, ingénieur, auteur* | *professeure*<br>*ingénieure*<br>*auteure* |
| *médecin* | *médecin* (la médecine, ce n'est pas une femme médecin ! ) |
| *sportif* | *sportive* |
