**مثال (٣) :**

جد الانحراف المعيارى لدرجات الطالب في المثال السابق

**الحل :**

الوسط الحسابى للمفردات من المثال السابق = ٧٣

| المفردة س       | ح = س – س<br>= س – ٧٣ | ( س – س )$^٢$ |
| --------------- | --------------------- | ------------- |
| ٧٥              | ٢                     | ٤             |
| ٨٢              | ٩                     | ٨١            |
| ٧٤              | ١                     | ١             |
| ٥٦              | ١٧–                   | ٢٨٩           |
| ٦٥              | ٨–                    | ٦٤            |
| ٧١              | ٢–                    | ٤             |
| ٩٣              | ٢٠                    | ٤٠٠           |
| ٥٨              | ١٥–                   | ٢٢٥           |
| ٨٣              | ١٠                    | ١٠٠           |
| Σ ( س – س )$^٢$ |                       | ١١٦٨          |

$ع^٢$ = $\frac{١١٦٨}{٩}$ = ١٢٩٫٧ ≃ ١٢٩٫٨

∴ ع = $\sqrt{١٢٩٫٨}$ = ١١٫٣٩

إن العلاقة ع = $\sqrt{\dfrac{Σ ( س – \overline{س} )^٢}{ن}}$

هى العلاقة الأساسية لتعريف الإنحراف المعيارى ولكننا إذا استخدمنا خواص رمز المجموع Σ نستطيع أن نتوصل إلى صيغة أخرى للانحراف المعيارى وذلك باستخدام مربعات مفردات المجموعة والوسط الحسابى للمفردات وهذه العلاقة هى :

ع = $\sqrt{\dfrac{Σس^٢}{ن} – \overline{س}^٢}$
