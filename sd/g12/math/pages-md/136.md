ح ( أ ∪ ب ) = ح ( أ ) + ح ( ب ) – ح ( أ – ب)

**دالة الاحتمال :**

مما سبق يتضح أنه يمكن تعريف دالة تقرن كل حدث من فضاء العينة ع بعدد معين من الفترة [ ٠ ، ١ ] كما يلى :

**(٥ – ٨ ) تعريف :**

> إذا كان ع هو فضاء العينة لتجربة عشوائية
>
> ق ( ع ) هى مجموعة أحداث هذا الفضاء ،
>
> ح هى مجموعة الأعداد الحقيقية فإن الدالة :
>
> ح : ق ( ع ) ← ح تسمى دالة احتمال
>
> إذا توفرت فيها الشروط التالية :
>
> ٠١ ح (أ) ≥ ٠ ،   ∀ أ ∈ ق ( ع )
>
> ٠٢ ح ( ع ) = ١
>
> ٠٣ إذا كان أ ∩ ب = ∅ ، ∀ أ ، ب ∈ ق ( ع )
>
> فإن ح ( أ ∪ ب ) = ح ( أ ) + ح (ب)
>
> وحيث أن ٠ ≤ ح ( أ ) ≤ 1 ∀ أ ∈ ق ( ع )
>
> فإن مدى دالة الاحتمال هو الفترة [ ٠ ، ١ ]

**مثال (١) :**

إذا كانت ع = { أ١ ، أ٢ ، أ٣ } هى فضاء لتجربة عشوائية ، فبين أى الدوال التالية تكون دالة إحتمال على ع مع ذكر السبب

(١) ح ( أ١ ) = ٠,٣   ،   ح( أ٢ ) = ٠,٦   ،   ح ( أ٣ ) = ٠,٢

(٢) ح ( أ١ ) = ٠,٥   ،   ح( أ٢ ) = ٠,٥   ،   ح ( أ٣ ) = ٠,٣

(٣) ح ( أ١ ) = ٠,٤   ،   ح( أ٢ ) = –٠,١   ،   ح ( أ٣ ) = ٠,٣

(٣) ح ( أ١ ) = ٠,٣   ،   ح( أ٢ ) = ٠,٤   ،   ح ( أ٣ ) = ٠,٣

(٥) ح ( أ١ ) = ٠,٦   ،   ح( أ٢ ) = ٠   ،   ح ( أ٣ ) = ٠,٤
