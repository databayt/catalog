## التكامل

### ( ٣ – ١ ) التكامل كعملية عكسية للتفاضل :

في التفاضل نعطى الداله ص في متغير ما س مثلاً ويطلب منا ايجـاد د ص / د س . في العملية العكسية نعطى د ص / د س ويطلب منا ايجاد الداله ص . هذه العملية العكسية تسمى بالتكامل فمثلاً إذا اعطينا

د ص / د س = ٢ س

بسهولة يمكن ايجاد ص = س$^٢$ ، وبملاحظة خاطفة نجد أن ص يمكن أن تساوى س$^٢$ + ١ أو س$^٢$ – ٧ أو س$^٢$ + أ وبصورة عامــة ص = س$^٢$ + ث ( ث ثابت ) كلها تمثل حلاً لايجاد ص إذا كان :

د ص / د س = ٢ س .

وبصورة عامة نفترض أن :

ص = د ( س )

فإذا كان د ص / د س = ر ( س )

فإننا نقول إن ص هى تكامل ر ( س ) بالنسبة لـــ س وتكتب

ص = ∫ ر ( س ) د س

ويساوى ذلك د ( س ) + ث حيث ث أى ثابت يسمى ثابت التكامل .
