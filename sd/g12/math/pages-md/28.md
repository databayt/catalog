الحل :

بتعويض س = – ١ ينتج (صفر ÷ صفر) وهي قيمة غير معينة

وعليه نلجأ إلى التحليل :

نها$_{س ← ١–}$ $\frac{٢ س^٢ + ٣س + ١}{س^٢ – ١}$ = نها$_{س ← ١–}$ $\frac{(٢س + ١) ( س + ١ )}{( س – ١ ) ( س + ١ )}$

= **نها**$_{س ← ١–}$ $\frac{٢ س + ١}{س – ١}$

= $\frac{٢ × (١–) + ١}{١– – ١}$

= $\frac{١–}{٢–}$

= $\frac{١}{٢}$
