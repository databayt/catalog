بما أن س$_١$ أى نقطة في نطاق أو مجال تعريف الدالة ص = د (س) فإن النهاية .

$$نها_{Δ س → ٠} \frac{د ( س + Δ س ) – د ( س )}{Δ س}$$

إن وجدت ، تعنى هندسياً ميل المماس لمنحنى الدالة ص = د ( س ) عند س ويسمى بالمشتقة الأولى للدالة ص بالنسبة س ، ويرمز للمشتقة بــ :

$$ص' \quad أو \quad \frac{د ص}{د س} \quad أو \quad د' ( س ) \quad أو \quad \frac{د}{د س} (د ( س ) )$$

وتسمى أيضاً بالمعامل التفاضلي الأول لــ ص بالنسبة لــ س وتسمى بمعدل تغير ص بالنسبة لــ س .

إذن نكتب :

$$د' ( س ) = نها_{Δ س → ٠} \frac{د ( س + Δ س ) – د ( س )}{Δ س}$$

سنتطرق لاحقاً إلى قواعد أساسية لإيجاد المشتقات الأولى للدوال المختلفة غير أنه يمكن إيجاد المشتقات مباشرة من التعريف وذلك بما يعرف بإيجاد المشتقة من المبادئ الأولية .

**مثال (١) :**

جد المشتقة الأولى للدالة ص = س$^٢$ من المبادئ الأولية ، ثم جد قيمتها العددية عند س = ٣ ، ماذا يعنى ذلك هندسياً ؟

**الحل :**

ص = د ( س ) = س$^٢$

$$د' ( س ) = نها_{Δ س → ٠} \frac{د ( س + Δ س ) – د ( س )}{Δ س}$$
