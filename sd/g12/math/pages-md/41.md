**الشكل ( ٢ – ٢ )**

- ل$_١$
- ب ( س$_١$ + Δ س ، د ( س$_١$ + Δ س ) )
- ل
- أ ( س$_١$ ، د ( س$_١$ ) )
- Δ س
- س$_١$
- س$_١$ + Δ س

فإذا تحركت ب نحو أ اقترب الوتر ل$_١$ شيئاً فشيئاً من المماس ل لمنحنى ص = د ( س ) عند أ ( س$_١$ ، د ( س$_١$ ) ) ومن ثم يقترب المقدار :

$$\frac{د ( س_١ + Δ س ) – د ( س_١ )}{Δ س}$$

نحــو ميــل المماس للمنحنــى عنــد أ ( س$_١$ ، د ( س$_١$ ) ) إذاً ميل المماس عند س = س$_١$ هو النهاية التى يستقر عندها المقدار :

$$\frac{د ( س_١ + Δ س ) – د ( س_١ )}{Δ س}$$

كلما اقتربــت ب مــن أ ( أي كلمــا اقتربت Δ س من الصفر ) .

إذن ميل المماس لمنحنى الدالة ص= د(س) عند س = س$_١$ هو النهاية.

$$نها_{Δ س → ٠} \frac{د ( س_١ + Δ س ) – د ( س_١ )}{Δ س}$$

بفرض وجود تلك النهاية .
