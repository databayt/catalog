### ( ١ – ٦ ) بعض النهايات المهمة :

(١) إذا كان ن عدداً صحيحاً موجباً فإن :

نها$_{س ← أ}$ $\frac{س^ن – أ^ن}{س – أ}$ = ن أ$^{ن–١}$

البرهان :

فك القوسين في المقدار التالى :

( س – أ ) ( س$^{ن–١}$ + أ س$^{ن–٢}$ + أ$^٢$ س$^{ن–٣}$ + ... + أ$^{ن–٢}$ س + أ$^{ن–١}$ )

= س$^ن$ + أ س$^{ن–١}$ + أ$^٢$ س$^{ن–٢}$ + ٠٠٠ + أ$^{ن–٢}$ س$^٢$ + أ$^{ن–١}$ س

– أ س$^{ن–١}$ – أ$^٢$ س$^{ن–٢}$ – ٠٠٠ – أ$^{ن–١}$ س – أ$^ن$ = س$^ن$ – أ$^ن$

∴ س$^ن$ – أ$^ن$ = ( س – أ ) ( س$^{ن–١}$ + أ س$^{ن–٢}$ + أ$^٢$ س$^{ن–٣}$ + ٠٠٠ + أ$^{ن–١}$ )

بالقسمة على س – أ

$\frac{س^ن – أ^ن}{س – أ}$ = س$^{ن–١}$ + أ س$^{ن–٢}$ + ... + أ$^{ن–٢}$ س + أ$^{ن–١}$

( لاحظ أن هناك ن من الحدود في الطرف الأيسر ) .

∴ نها$_{س ← أ}$ $\frac{س^ن – أ^ن}{س – أ}$ = نها$_{س ← أ}$ ( س$^{ن–١}$ + أ س$^{ن–٢}$ + ٠٠٠ + أ$^{ن–٢}$ س + أ$^{ن–١}$ )

= أ$^{ن–١}$ + أ$^{ن–١}$ + ٠٠٠ + أ$^{ن–١}$

= ن أ$^{ن–١}$ وهو المطلوب

مثال (١) :

نها$_{س ← ٥}$ $\frac{س^٤ – ٥^٤}{س – ٥}$ = ٤ × ٥$^{٤–١}$

= ٤ × ١٢٥

= ٥٠٠
