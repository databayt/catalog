(٥) حادثة ظهور عدد زوجى وعدد فردى .

**الحل :**

من الواضح أن :

أ = { ٢ ، ٤ ، ٦ }

ب = { ١ ، ٣ ، ٥ }

ج = { ٥ ، ٦ }

د = { ٣ ، ٦ }

وبالتالى فإن :

(١)  أ ∩ د = { ٦ }

(٢) ب ∪ ج = { ١ ، ٣ ، ٥ ، ٦ }

(٣) ب ∪ أ = { ١ ، ٢ ، ٣ ، ٤ ، ٥ ، ٦ }

(٤) ب ∩ ج = { ٥ }

(٥) أ ∩ ب = $\varnothing$

**الحوادث المنفصلة أو المتنافية :**

### (٥ – ٥) تعريف :

نقول أن الحادثتين أ ، ب متنافيتان أو منفصلتان إذا كان تقاطعهما المجموعة الخالية أى أ ∩ ب = $\varnothing$

وتنافى حادثتين يعنى أنه لايمكن وقوعهما معاً ، وهذا واضح من عدم وجود أى نقطة عينة مشتركة بينهما أو أن وقوع إحدى الحادثتين ينفى إمكانية وقوع الأخرى كما في الحالة ٥ في المثال السابق .
