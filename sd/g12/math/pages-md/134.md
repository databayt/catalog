**البرهان :**

∵ ع = أ ∪ أ ′

∴ ح ( ع ) = ح ( أ ∪ أ ′ )

وحيث أن أ ∩ أ ′ = ∅

∴ ح ( ع ) = ح ( أ ) + ح ( أ ′ ) مسلمة (٣)

∴ ١ = ح ( أ ) + ح ( أ ′ ) مسلمة (٢)

∴ ح ( أ ′ ) = ١ – ح ( أ )

### نتيجة (٥ – ١) :

ح (∅) = صفر .

**البرهان :**

ع ′ = ∅

لكن ح ( ع ′ ) = ١ – ح (ع)

∴ ح ( ع ′ ) = ١ – ١ = صفر

∴ ح (∅)= صفر

### (٥ – ٢) نظرية :

> إذا كان أ ⊃ ب فإن :
> ح ( أ ) ≥ ح ( ب )

**البرهان :**

∵ أ ⊃ ب

∴ ب = أ ∪ ( ب – أ )

( أستعن بشكل **ڤن** )

∴ ح (ب) = ح ( أ ∪ ( ب – أ ) )

وحيث أن :

أ ∩ ( ب – أ ) = ∅ (حدثان متنافيان)
