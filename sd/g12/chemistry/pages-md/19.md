**مثال (1-7) :** تحضير كلورو إثيان من الإيثيلين (الإيثين) :

$CH_2 = CH_2 + HCl ⟶ CH_3 - CH_2Cl$

(إيثين) &nbsp;&nbsp; (كلوريد هيدروجين) &nbsp;&nbsp; (كلورو ايثان)

**مثال (1-8) :** تحضر &nbsp; 2– يودو – بروبان من البروبين :

```
                                          I    H
                                          |    |
  CH3 – C = C – H + HI ————→    CH3 –  C  –  C – H
         |   |                            |    |
         H   H                            H    H
```

(بروبين) &nbsp;&nbsp; (يوديد هيدروجين) &nbsp;&nbsp; (2 – يودو – بروبان)

**ملاحظة :** يُلاحظ أن ذرة الهيدروجين في جزئ HI ترتبط بــذرة الكربــون التــي يرتبط بها أكبر عدد من ذرات الهيدروجين حسب (قاعدة مــاركوفينوكوف) التــي تنص على الآتي :

(عند تفاعلات الإضافة إلى الرابطــة الثنائيــة $C = C -$ – أو الثلاثيــة ، يُلاحظ أن ذرة الهيدروجين تضاف إلى ذرة الكربون التي يرتبط بها أكبر عدد مــن ذرات الهيدروجين).

**مثال (1-9) :** تحضير مركب كلورو بروبان حلقي (مثال على الهيــدروكربونات الحلقية غير المشبعة) :

```
       CH                              CH2
      /  \                            /   \
  CH2 – C – H        + HCl ————→   CH2 – CHCl
```

(بروبين حلقي) &nbsp;&nbsp; (كلوريد هيدروجين) &nbsp;&nbsp; (كلورو بروبان حلقي)
