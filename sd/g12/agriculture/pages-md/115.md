يوجد مترسباً بين الحزم العضلية وبين العضلات . الدهن المترسب بين الحزم العضلية يسمى دهن التعريق ( Marbling fat ) أو دهن داخل العضلات .

**د ) الكربوهيدرات : ( Carbohydrates ) :**

تحتوي اللحوم على نسبة قليلة من المواد الكربوهيدراتية ويعد الجلايكوجين ( Glycogen ) أكثر أنواع الكربوهيدرات وفرة في العضلات ، وتتراوح نسبته ما بين ( ٠٫٥ – ٣٫١٪ ) من وزن العضلة .

**هـ ) المعادن والأملاح :**

وهي مهمة جداً لوظيفة العضلات ، ومن أهم الأملاح والمعادن التي توجد في اللحم ما يأتي :

الكالسيوم ( Ca ) والماغنسيوم ( Mg ) والبوتاسيوم ( K ) والصوديوم ( Na ) والحديد ( Fe ) والفسفور ( P ) والكبريت ( S ) والكلور ( Cl ) .

**أسئلة :**

١–    عرف التالي :

أ/ اللحم        ب/ الذبيحة      ج/ الألياف العضلية .

٢–    عدّد أقسام اللحوم و العضلات .

٣–    بالرسم التوضيحي فقط وضح الآتي :

أ )      قطاع عرضي للعضلة الهيكلية .

ب )     شكل الخويطات السميكة والرفيعة .
