وفي القرص الأول C . ربما يسأل كذلك لينوكس أثناء الإنزال عن عدد المسارات في القرص وعدد الاسطح وعدد المقاطع في المسار الواحد وهذه المعلومات تكون عادة مطبوعة على القرص من الخارج .

ثالثاً : بعض أوامر لينوكس الهامة وما يقابلها في UNIX وDOS

| LINUX | UNIX | DOS |
| --- | --- | --- |
| Ls / dir | ls | dir |
| clear | clear | cls |
| rm | rm | del |
| cp | cp | copy |
| mv | mv | move / rename |
| cat | cat | type |
| cd | cd | cd |
| more file | more file | more < file |
| mkdir | mkdir | md |
| Rmdir | rmdir | rd |

جدول يوضح بعض الأوامر المستخدمة في أنظمة التشغيل : Dos , UNIX , Linux
