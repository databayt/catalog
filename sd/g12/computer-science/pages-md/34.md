مثال (٢٣) :

٧ = ١١١

+ ٩ = ١٠٠١

= ١٦ = ١٠٠٠٠

إذن $(١٦)_{١٠}$ = $(١٠٠٠٠)_{٢}$ = $٠×٢^{٠}+٠×٢^{١}+٠×٢^{2}+٠×٢^{3}+١×٢^{4}$

= ٠+٠+٠+٠+١٦ = ١٦

مثال (٢٤) :

اجمع ٣٨ + ٥٩ + ٨٨

نجمع أولا ٣٨ + ٥٩

٣٨ = ١٠٠١١٠

+ ٥٩ = ١١١٠١١

= ٩٧ = ١١٠٠٠٠١

+ ٨٨ = ١٠١١٠٠٠

= ١٨٥ = ١٠١١١٠٠١

إذن $(١٨٥)_{١٠}$ = $(١٠١١١٠٠١)_{٢}$

= $١×٢^{٠}+٠×٢^{١}+٠×٢^{2}+١×٢^{3}+١×٢^{4}+١×٢^{5}+٠×٢^{6}+١×٢^{7}$

= ١+٠+٠+٨+١٦+٣٢+٠+١٢٨ = ١٨٥
