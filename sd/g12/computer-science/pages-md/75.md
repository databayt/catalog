حلقة Repeat ... Until:

نستخدم هذا النمط من الحلقات التكرارية إذا كان تكرار العمل يتوقف علي شرط معين .

الصيغة العامة

```
Repeat
    <أي تتابع من العبارات البسيطة أو المركبة
Until <تعبير بوليائي
```

حلقة While ... Do:

نستخدم هذا النمط من الحلقات التكرارية إذا كان تكرار العمل يتوقف علي شرط معين .

الصيغة العامة

```
While < تعبير بوليائي > do
        <عبارات بسيطة أو مركبة
```

عبارة IF ... THEN ... ELSE :

الصيغة العامة

```
IF < تعبير بوليائي > Then
        <عبارات بسيطة أو مركبة
Else
        <عبارات بسيطة أو مركبة
```
