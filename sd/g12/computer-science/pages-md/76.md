(مثـــال ٦):

اكتب برنامجاً بلغة بسكال يقوم بطباعة "نجاح" اذا كانت درجة أكبر أو تساوي ٥٠ وإلا يطبع "رسوب"

```
Var
score: shortint ;
Begin
        Write(`إدخل درجة الطالب’);
        Readln(score);
If score>=50 then
    Writeln(`نجاح’)
        Else
Writeln(`رسوب’);
End.
```

(مثـــال ٧):

أكتب برنامجاً بلغة بسكال يقوم بطباعة "حرف علة " إذا كان الحرف المدخل أحد حروف العلة "A,E,I,O,U" وإلا يطبع "ليس حرف علة"

```
Var
C: Char ;
Begin
        Write(`أدخل أي حرف’);
        Readln(C);
        C:=Upcase(C);
If (C=’A’)OR (C=’E’)OR (C=’I’)OR
(C=’O’)OR (C=’U’)OR then
    Writeln(`حرف علة’)
        Else
Writeln(`ليس حرف عله’);
End.
```
