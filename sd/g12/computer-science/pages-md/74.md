(مثـــال ٤):

اكتب برنامجاً بلغة بسكال يقوم بحساب مجموع مربعات الأعداد من a إلى b حيث  b ثم الوسط الحسابي لها : a>b

```
Var
I, S,a,b : integer ;
Avg : real;
Begin
        ReadLn (a, b);
        S:=0;
        For I:=a to b do
            S:=S +I*I;
        Avg:=S/(b–a+1);
        Writeln(` مجموع مربعات الأعداد = ’, S);
        Writeln(` المتوسط = ’,Avg);
End.
```

(مثـــال ٥):

اكتب برنامجاً بلغة بسكال يقوم بحساب مضروب أي عدد N

```
Var
I,N: shortint ;
Fact : Longint;
Begin
        Write(`ادخل العدد’);
ReadLn (N);
        Fact :=1;
        For I:=N downto 1 do
            Fact:=Fact*I;
        Writeln(` مضروب العدد = ’,Fact);
End.
```
