هو الحجم الذي تشغله عند درجة ٥٧ درجة مئوية عند ثبوت الضغط .

الحل :

المعطيات : ح$_{27}$ = ٢٠٠ مليلتر ( حجم الغاز عند °٢٧ )

د$_{27}$ = ٢٧ + ٢٧٣ = ٣٠٠ كلفن

د$_{57}$ = ٥٧ + ٢٧٣ = ٣٣٠ كلفن

المطلوب إيجاد ح$_{57}$ ( حجم الغاز عند °٥٧ )

بما ان الضغط ثابت فإن:

$\frac{ح_{27}}{د_{27}}$ = $\frac{ح_{57}}{د_{57}}$

ح$_{57}$ = $\frac{ح_{27}}{د_{27}}$ X د$_{57}$ = $\frac{٢٠٠ X ٣٣٠}{٣٠٠}$ = ٢٢٠ مليلتر

لماذا زاد الحجم ؟

مثال ( ٤–١٢ ) :

كتلة محدودة من الغاز تحتل حجم لتر واحد عند درجة حرارة ٢٥ مئوية . سُخنت الكتلة إلى درجة حرارة ٢٥٠ مئوية بزيادة الضغط إلى ضعفه، اوجد الحجم النهائي للغاز .
