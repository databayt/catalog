### ( ٣–١–٤ ) مواصفات أداء المولد مع الحمل الكهربائي :

يمكن تشبيه المولد الكهربائي بمصدر قدرة كهربائية مثل المركم العادي . ويلاحظ أن جميع مصادر القدرة الكهربائية يمكن تمثيلها بمصدر قدرة مثالي موصل على التوالي مع مقاومة داخلية صغيرة . وفي حالة الماكينات الكهربائية توجد مقاومة الموصلات المستخدمة في المولد الكهربائي . وعندما يمرر التيار من المولد وخلال مقاومة الحمل فإن ذلك يتسبب في هبوط فولتية المقاومة الداخلية للمولد فتنخفض الفولتية عند طرفي المولد والحمل .

وقد جُمعت المقاومة الموزعة في مقاومة داخلية واحدة يشار إليها بالرمز ( مد ) .

ولهذا فإن المعادلة للدائرة المكونة من المقاومة الداخلية ( مد ) لعضو الإنتاج، ومقاومة الحمل ( مح ) هي :

ف = ي – ت X مد .... ( ٣–٤ )

حيث : ف = الفولتية بين طرفي المولد

ي = قوة الدفع الكهربائية المنتجة داخلياً في عضو الإنتاج في المولد

ت = تيار عضو الإنتاج

مد = المقاومة الداخلية للمولد، أي مقاومة عضو الإنتاج .

وبما أن تيار عضو الإنتاج ( ت ) = $\frac{ف}{مح}$

حيث ( ف ) الفولتية بين طرفي المولد، و ( مح ) مقاومة الحمل فإن :

ف = ت X مح ...... ( ٣–٥ )

عوض المعادلة ( ٣–٥ ) في المعادلة ( ٣–٤ ) :

ت X مح = ي – ت X مد

ي = ت X مح + ت X مد

ي = ت X ( مح + مد )

∴ ت = $\frac{ي}{مح + مد}$ ...... ( ٣–٦ )
