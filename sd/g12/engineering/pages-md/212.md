المساحة الكلية بين خطوط الأمطار المتساوية ، لتقدير التساقط المتوسط لهذه المنطقة ، كما موضح في المعادلة ( ٤–١٧ ) .

$م = \frac{م_١(ص_١ + ص_٢) + م_٢(ص_٢ + ص_٣) + .... + م_ن(ص_ن + ص_{ن+١})}{٢ ( م_١ + م_٢ + م_٣ + ............ + م_ن )}$ .. ( ٤–١٧ )

م = متوسط التساقط في المنطقة .

$ص_ن$ = التساقط على خط الأمطار المتساوية ن .

$م_ن$ = المساحة بين زوج من خطوط الأمطار المتساوية .

مثال( ٤–١٨ ) :

اوجد التساقط المتوسط في منطقة جابية طبقاً للمعلومات والبيانات الموضحة في الجدول أدناه  باستخدام طرق مختلفة لتقديرها :

| المحطة | مقياس المطر ( سم ) | المساحة ( ٪ ) |
|---|---|---|
| ١ | ٥٠ | ٩ |
| ٢ | ٦٢ | ١٣ |
| ٣ | ٧٥ | ١٧ |
| ٤ | ١٠٠ | ٢٠ |
| ٥ | ١٠٦ | ٣٠ |
| ٦ | ٩٥ | ١١ |

الحل :

١– جد  متوسط الأمطار الهاطلة بالمنطقة باستخدام طريقة المتوسط الحسابي من المعادلة :

$م = \frac{ص_١ + ص_٢ + ص_٣ + ............. + ص_ن}{ن}$
