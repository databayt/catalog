الفائدة الميكانيكية = نسبة السرعة

$\therefore$ الفائدة الميكانيكية = ١٠

ولكن

$\text{الفائدة الميكانيكية} = \frac{\text{المقاومة}}{\text{القوة}}$

$١٠ = \frac{٤٠}{\text{القوة}}$

$\text{القوة} = \frac{٤٠}{١٠}$ = ٤ نيوتن

٢– عندما تكون كفاءة الرافعة ٨٠ ٪ = ٠,٨ :

$\text{الكفاءة} = \frac{\text{الفائدة الميكانيكية}}{\text{نسبة السرعة}}$

$٠,٨ = \frac{\text{الفائدة المكانيكية}}{١٠}$

$\therefore$ الفائدة الميكانيكية = ٨

ولكن

$\text{الفائدة الميكانيكية} = \frac{\text{المقاومة}}{\text{القوة}}$

$٨ = \frac{٤٠}{\text{القوة}}$

$\therefore \text{القوة} = \frac{٤٠}{٨}$ = ٥ نيوتن

$\therefore$ القوة اللازمة هي ٥ نيوتن عندما تكون كفاءة الرافعة ٨٠ ٪ .

٢– **النوع الثاني:** هي الرافعة التي يكون فيها الحمل بين المجهود ومحور الارتكاز كما في الشكل ( ٢–٣ ) ادناه .

ومن أمثلتها كسارة البندق ( كسارة بذور ) شكل ( ٢–٢ ) وهراسة الثوم وعصارة الليمون وعربة اليد المستعملة في الحدائق ( عربة البستاني أو الدردقة ) ومجداف المركب عندما يكون في الماء .
