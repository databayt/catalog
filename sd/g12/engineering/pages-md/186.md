القوي المستعرضة هي القوى المتعامدة مع المحور الطولي للعارض .

مثال( ٤–١٠ ) :

ارسم مخطط قوى القص للكابولي في الشكل( ٤–٢٦ ) الذي تعمل عليه قوة ق وطوله ل .

![الشكل( ٤–٢٦ ) : كابولي .](pages/186.webp)

**الشكل( ٤–٢٦ ) : كابولي .**

- ق
- ل

الحل :

لأي مقطع( أ – أ ) على بعد( س ) من القوة "ق" كما موضح بالشكل( ٤–٢٧ ) أدناه فإن قوة القص تساوي( – ق ) بغض النظر عن المسافة( س ) من نقطة عمل القوة مما يجعل مخطط قوى القص للكابولي عبارة عن مستطيل .

![شكل ( ٤–٢٧ ) : مخطط قوى القص](pages/186.webp)

**شكل ( ٤–٢٧ ) : مخطط قوى القص**

- ق

- س
