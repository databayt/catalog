الحل :

د = ر ز

حيث : د = التردد

ر = سرعة الدوران ( دورات / ثانية ) = ١٠٠ دورة / ثانية

ز = عدد أزواج الأقطاب = $\frac{٦}{٢}$ = ٣

وعليه فإن التردد د = ١٠٠ X ٣ = Hz ٣٠٠

مثال (٣–٨) :

تردد ق . د . ك المنتجة من مولد ( د ) = ٥٠ هيرتز . فإذا كانت سرعة دوران المولد تساوي ١٠٠٠ لفة / دقيقة، ما عدد الأقطاب في المولد ؟

الحل :

د = Hz ٥٠

ر = سرعة الدوران ( دورات / ثانية ) = $\frac{١٠٠٠}{٦٠}$ دورات / ثانية

ز = $\frac{د}{ر}$ = $\frac{٥٠}{١٠٠٠}$ X ٦٠ = ٣

عدد الأقطاب = ٣ X ٢ = ٦ أقطاب .

مثال (٣–٩) :

مولد ذو ٨ أقطاب ينتج ق . د . ك ذات تردد Hz ١٠٠ ، جد سرعة دوران المولد .

الحل :

د = ر ز

حيث : د = التردد = Hz ١٠٠

ز = عدد أزواج الأقطاب = $\frac{٨}{٢}$ = ٤

ر = سرعة الدوران ( دورات / ثانية ) = $\frac{د}{ز}$ = $\frac{١٠٠}{٤}$ = ٢٥ دورة / ثانية .

السرعة = ٢٥ X ٦٠ = ١٥٠٠ دورة / دقيقة .
