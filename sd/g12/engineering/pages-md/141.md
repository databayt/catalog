### تمارين( ٣-٥ )

( ١ ) مصدر قدرة كهربائية ثلاثي الأطوار موصل على طريقة النجمة، فإذا كان جهد الطور يساوي ٢٣٠ فولت وتيار الخط $ت_ل$ يساوي ٥ أمبير. أحسب تيار الطور وجهد الطور .

( ٢ )مصدر قدرة كهربائية ثلاثي الأطوار موصل على طريقة الدلتا . إذا كان تيار الخط ١٠ أمبير وفولتية الخط ٤١٥ فولت. أحسب ( ١ ) تيار الطور . ( ٢ ) فولتية الطور .

( ٣ ) ثلاثة أحمال مقاومة كل واحد منها ٣٠ أوم وصلت بطريقة النجمة لمصدر جهد ثلاثي الأطوار ٤١٥ فولت جد : ( أ ) جهد الطور للأحمال ( ب ) تيار الطور ( ج ) تيار الخط .

( ٤ ) ثلاثة ملفات متشابهة مقاومة كل منها ٣٠ أوم ومفاعلتها الحثية $ع_ل$ = ٤٠ أوم. إذا كان تيار الخط ٥ أمبير فأحسب جهد الخط إذا وصلت الملفات : ( أ ) نجمة ( ب ) دلتا .

( ٥ ) ثلاثة مكثفات متشابهة وصلت بطريقة الدلتا بين أطراف مصدر ثلاثي الأطوار ٤١٥ فولت، ٥٠ هيرتز . إذا كان تيار الخط $١٥\sqrt{٣}$ أمبير فأحسب سعة كل مكثف .
