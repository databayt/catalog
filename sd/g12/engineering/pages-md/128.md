### ( ٣–٣–٦ ) المفاعلة الحثية :

عندما يمر تيار ذو تردد معلوم ( د ) في دائرة بها محاثة فقط، فإن النسبة $\frac{ف}{ت}$ تعطي مقداراً ثابتاً لأي ملف ذي محاثة محددة ( ل ) . ويسمى هذا الثابت بالمفاعلة ( ع ) ووحدته أوم . وبالنسبة للملف يسمى هذا الثابت بالمفاعلة الحثية $ع_ل$ . ويمكن حساب المفاعلة الحثية $ع_ل$ من معامل المحاثة ل ( هنري ) والتردد د ( هيرتز ) كما يلي :

$ع_ل$ = ٢ π د ل ( أوم ) ...... ( ٣–٢٠ )

مثال( ٣–١٣ ) :

ملف ذو محاثة ٠,٤٥ هنري، وصل إلى مصدر قدرة كهربائية ذي فولتية ٢٠٠ V وتردد ٥٠ Hz، جد :

( ١ ) مقدار المفاعلة السعوية .

( ٢ ) مقدار التيار المتردد الذي سوف يمر بالدائرة .

الحل :

المفاعلة الحثية $ع_ل$ = ٢ π د ل

حيث : $ع_ل$ = المفاعلة الحثية .

ل = معامل الحث الذاتي = ٠,٤٥ H

د = التردد = ٥٠ Hz

ف = فولتية المصدر = ٢٠٠ V

( ١ ) المفاعلة الحثية = ٢ π X ٥٠ X ٠,٤٥ = ١٤١,٤ Ω

( ٢ ) التيار = $\frac{ف}{ع_ل}$ = $\frac{٢٠٠}{١٤١,٤}$ = ١,٤١ A
