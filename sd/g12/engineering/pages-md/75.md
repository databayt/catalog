![شكل ( ٢–٢١ ) : القوة موازية للمستوى المائل .](pages/75.webp)

**شكل ( ٢–٢١ ) : القوة موازية للمستوى المائل .**

- ج
- القوة
- معطى : أج = ١٠متر
- ب ج = ١٠٠ متر
- ب
- أ
- ثقل الجسم

نسبة السرعة = $\frac{طول المستوى المائل}{الإرتفاع الرأسي}$ = $\frac{١٠٠}{١٠}$ = ١٠

كفاءة الآلة = ١٠٠ ٪ = ١ ( نظراً لاهمال قوة الاحتكاك )

∴ الفائدة الميكانيكية = نسبة السرعة = ١٠

الفائدة الميكانيكية = $\frac{ثقل الجسم}{القوة}$

١٠ = $\frac{١٠٠٠}{القوة}$

القوة المؤثرة = $\frac{١٠٠٠}{١٠}$ = ١٠٠
