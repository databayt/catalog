في الشكل( ٤–١١ )( ب ) :

استبدلت القوة "ق" بمركباتها ( ق . جتاθ ) و( ق . جاθ ) .

عزم المركبتين حول نفس النقطة "م" = ( ق . جتاθ ) × ( ب م ) + ( ق . جاθ ) × ( د م )

$= ( ق \times \frac{ص}{ف} ) \times ص + ( ق \times \frac{س}{ف} ) \times س$

" " " $= \frac{ق}{ف} \times ( ص^٢ + س^٢ )$
