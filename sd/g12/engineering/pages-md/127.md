حساب المفاعلة السعوية $ع_س$ من مقدار المواسعة س ( فاراد ) والتردد د ( هيرتز ) كما يلي :

$ع_س$ = $\frac{١}{٢ \pi د س}$ ( أوم ) ...... ( ٣–١٩ )

مثال( ٣–١٢ ) :

مكثف مواسعته ٢٢ μF ، وصل إلى مصدر قدرة كهربائية ذي فولتية V.٢٠٠ وتردد ٥٠ Hz . جد :

( أ ) مقدار المفاعلة السعوية ( ب ) مقدار التيار المتردد الذي سوف يمر بالدائرة .

الحل :

( ١ ) $ع_س$ = $\frac{١}{٢ \pi د س}$

حيث : $ع_س$ = المفاعلة السعوية .

س = المواسعة = ٢٢ μF

د = التردد = ٥٠ Hz

ف = فولتية المصدر = V.٢٠٠

$ع_س$ = $\frac{١}{٢ \pi ٥٠ X ٢٢ X ١٠^{-٦}}$ = ١٤٤,٧ Ω

( ٢ ) التيار = $\frac{ف}{ع_س}$ = $\frac{٢٠٠}{١٤٤,٧}$ = ١,٣٨ A
