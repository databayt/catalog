مثال (٢) :

جد معادلة الدائرة التى مركزها   ( ٢ ، – ٣ ) ، ونصف قطرها   ٤ وحدات .

الحل :

∵  ( س – د )² + ( ص – هـ )² = نق²

وبالتعويض عن ( د ، هـ ) بالنقطة ( ٢ ، ⁻٣ ) ، نق = ٤ فان معادلة الدائرة المطلوبة  هى :

( س – ٢ )² + ( ص – ⁻٣ )² = ٤²

أو ( س – ٢ )² + ( ص + ٣ )² = ١٦

مثال (٣) :

جد مركز وطول نصف قطر الدائرة التى معادلتها  :

( س + ١ )² + ص² = ٢٥

الحل :

بوضع المعادلة على الصورة : ( س – د )² + ( ص – هـ )² = نق²

تصبح : ( س – ⁻١ )² + ( ص – ٠ )² = ٥²

∴ المركز  ( ⁻١ ، ٠ ) ، نق = ٥

### تمرين ( ٦ – ١ )

(١)  اكتب معادلة الدائرة التى مركزها نقطة الأصل وطول نصف قطرها ٦ وحدات .

(٢)  اكتب معادلة الدائرة التى مركزها  ( ٠ ، –٣ ) وطول نصف قطرها ٧ وحدات .
