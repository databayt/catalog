$$٨ + ١٨ - ٢ - ١٥ - ٩ = ٢٦ - ٢٦ = ٠$$

= الطرف الأيسر

∴ النقطة ( ٢ ، ⁻٣ ) تقع على الدائرة . بالقسمة على ٢ لجعل معاملى $س^٢$ ، $ص^٢$ يساويان الواحد الصحيح :

$$س^٢ + ص^٢ - \frac{١}{٢} س + \frac{٥}{٢} ص - \frac{٩}{٢} = ٠$$

∴ $ل = - \frac{١}{٤}$ ، $ك = \frac{٥}{٤}$ ، $جـ = \frac{-٩}{٢}$

∴ معادلة المماس :

$$٢ س - ٣ ص - \frac{١}{٤} ( س + ٢ ) + \frac{٥}{٤} ( ص - ٣ ) - \frac{٩}{٢} = ٠$$

∴ $٢ س - ٣ ص - \frac{١}{٤} س - \frac{١}{٢} + \frac{٥}{٤} ص - \frac{١٥}{٤} - \frac{٩}{٢} = ٠$

$$٧ س - ٧ ص - ٣٥ = ٠$$

∴ $س - ص - ٥ = ٠$
