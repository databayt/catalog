( لأن أ = ( أ – ب ) ∪ ( أ ∩ ب) وهما متنافيان )

∴ ح ( أ – ب ) = $\frac{٣}{٥}$  –  $\frac{١}{٥}$   =  $\frac{٢}{٥}$

(هـ) ح ( ب – أ ) = ح (ب) – ح ( أ ∩ ب)

=  $\frac{١}{٤}$  –  $\frac{١}{٥}$   =  $\frac{١}{٢٠}$

(و ) ح ( أ ′ ∪ ب) = ح ( أ ′ ) + ح (ب) – ح ( أ ′ ∩ ب)

=  ح ( أ ′ ) + ح (ب) – ح ( ب – أ )

( لأن أ ′ ∩ ب = ب – أ )

=  $\frac{٢}{٥}$ + $\frac{١}{٤}$  –  $\frac{١}{٢٠}$   =  $\frac{٣}{٥}$

(ز) ح ( أ ∩ ب′) = ح ( أ – ب ) = $\frac{٢}{٥}$

(ح) ح ( أ ′ – ب) = ح ( أ ′ ∩ ب′) = ح ( أ ∪ ب )′

= ١ – ح ( أ ∪ ب)

= ١ –  $\frac{١٣}{٢٠}$ = $\frac{٧}{٢٠}$
