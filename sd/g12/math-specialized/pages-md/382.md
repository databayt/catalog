### تمرين ( ٧ – ٥ )

(١) حل المعادلات التالية :

( أ ) ٤ $ع^٢$ – ١٢ ع + ١٣ = ٠

(ب) $ع^٢$ – ٤ ع + ٧ = ٠

(جـ) $ع^٢$ – ( ٥ + ٧ ت ) ع + ( –٦ + ١٧ ت ) = ٠

(د) ٤$ع^٢$ + ٢٥ = ٠

(هـ) $ع^٢$ – ٢ ت ع + ٣ = ٠

(٢) جد بقية جذور المعادلة  $ع^٤$ + ٤ $ع^٢$ + ١٦ = ٠ علماً بأن :
ع = ١ + $\sqrt{٣}$ ت جذراً لها .

(٣) ما المعادلة التربيعية ذات المعاملات الحقيقية والتي أحد جذريها هو :

( أ ) – ت

( ب ) ٥ + ت

( جـ ) $\frac{\sqrt{٣} – ٤ ت}{٥}$

( د ) ٢ – $\sqrt{٣}$ ت

(٤) جد مجموع وحاصل ضرب جذري المعادلة .
( ١ + ٤ ت ) $ع^٢$ + ( ٥ – ٣ ت ) ع + ( ٨ – ٢ ت ) = ٠

(٥) تحقق أن ٣ ت جذراً للمعادلة :  ٣ $ع^٣$ + ٧ $ع^٢$ + ٢٧ ع + ٦٣ = ٠
ثم جد باقي الجذور .

### ( ٧ – ٦ ) الجذور التكعيبية للواحد الصحيح :

سبق أن عرفنا أنه لأي عدد حقيقي أ يوجد جذر تكعيبي حقيقي واحد يحقق المعادلة  $ع^٣$ = أ ويكتب على الصورة  $\sqrt[٣]{أ}$  . أما في مجموعة الأعداد المركبة فسنجد أن هناك ثلاثة جذور تكعيبية للعدد الحقيقي .

وسنتناول أولاً الجذور التكعيبية للواحد الصحيح أي حلول المعادلة

$ع^٣$ = ١ أو $ع^٣$ – ١ = ٠

وبتحليل الطرف الأيمن نحصل على :

( ع – ١ ) ( $ع^٢$ + ع + ١ ) = ٠ فيكون :

إما ع – ١ = ٠ ومنها  ع = ١

أو $ع^٢$ + ع + ١ = ٠
