وبإضافة ر + ١ للطرفين نجد أن :

١ + ٢ + ٣ + ...... + ر + ( ر + ١ ) = ر ( ر + ١ ) / ٢ + ( ر + ١ )

أو

١ + ٢ + ٣ + ..... + ر + ( ر + ١ ) = ( ر + ١ ) ( ١ + ر / ٢ )

= ( ر + ١ ) ( ر + ٢ ) / ٢

وهذا يعني أن العلاقة صحيحة عند ن = ر + ١ ، ووفقاً لمبدإ الاستنتاج الرياضي تكون العلاقة صحيحة لكل ن ∈ ط.

مثال (٢) :

اثبت أن :

١ + ٣ + ٥ + ٧ + ...... + ( ٢ ر – ١ ) = ر²  حيث ن ∈ ط

الحل :

(١) عند ن = ١ يصبح الطرف الأيمن ١ .

والطرف الأيسر ١² = ١

أي أن العلاقة صحيحة عند ن = ١

(٢) لنفرض أن العلاقة صحيحة عند ن = ر ، أي لنفرض أن :

١ + ٣ + ٥ + ...... + ( ٢ ر – ١ ) = ر²

بإضافة الحد ( ٢ ر + ١ ) للطرفين

١ + ٣ + ٥ + ...+ ( ٢ ر – ١ ) + ( ٢ ر + ١ ) = ر² + ( ٢ ر + ١ )

أو :

١ + ٣ + ٥ + ...+ ( ٢ ر + ١ ) = ( ر + ١ )²
