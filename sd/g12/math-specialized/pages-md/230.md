مثال (١) :

احسب متوسط معدل التغير للدالة  ص = د ( س )  =  √( س – ٢ ) عندما تتغير س من ٣ إلى ٣,٢١ .

الحل :

Δ ص = د ( س + Δ س ) – د ( س )

س = ٣ ، Δ س = ٣,٢١ – ٣ = ٠,٢١

∴ Δ ص = د ( ٣,٢١ ) – د ( ٣ ) = √( ٣,٢ – ٢ )  –  √( ٣ – ٢ )

= √( ١,٢١ ) – √( ١ ) = ١,١ – ١ = ٠,١

∴ Δ ص / Δ س  =  ٠,١ / ٠,٢١  =  ١٠ / ٢١  ≈ ٠,٤٧٦

مثال (٢) :

تتمدد صفيحة دائرية بالتسخين . احسب متوسط معدل التغير في مساحتها عندما يتغير طول نصف قطرها من ٦ سم إلى ٦,١ سم .

الحل :

نفرض أن طول نصف القطر = نق

مساحة الصفيحة م = د ( نق ) = π نق²

Δ م / Δ نق  =  ( د ( ٦,١ ) – د ( ٦ ) ) / ( ٦,١ – ٦ )  =  π [ ( ٦,١ )² – ٦² ] / ٠,١

=  π ( ٦,١ – ٦ ) ( ٦,١ + ٦ ) / ٠,١  =  π × ٠,١ × ١٢,١ / ٠,١

= ١٢,١ π
