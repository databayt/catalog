(٣)  د / د س  ( قتا س )  =  – ظتا س قتا س

### تمرين ( ٢ – ٤ )

جد قيمة  د ص / د س  في كل من الحالات التالية :

(١) ص = س⁴ + ٣ س² + ٥

(٢) ص = ٥ س³ + ٢ س² + س + ١

(٣) ص = ١ + س + جا س

(٤) ص  =  ١ / س  +  ٥ جا س

(٥) ص  =  س / ( ١ + جا س )

(٦) ص = س² جا س

(٧) ص  =  ( ٢ س + ٣ ) / ( س – ٢ )

(٨) ص  =  ( س² – ٩ ) / ( س² – ٥ )

(٩) ص = ( جا س + ١ ) ( س² – س )

(١٠)ص  =  ٣ س² / ( س + ١ )

(١١)ص  =  ( س⁵ – س⁴ + ٣ س² ) / ( ٢س + ٧ )

(١٢) ص  =  ( س² – ١ ) / ( س³ + ١ )
