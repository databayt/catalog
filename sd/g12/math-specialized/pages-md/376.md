مثال (٥) :

جد جذور المعادلة : $ع^٤$ + ت ع = ٠

الحل :

$ع^٤$ + ت ع = ٠   ∴ ع ( $ع^٣$ + ت ) = ٠

أما ع = ٠ وهو احد الجذور   أو $ع^٣$ = – ت

∴ الجذور الأخرى هي الجذور التكعيبية للعدد – ت

∴ في العدد – ت ، أ = ٠ ، ب = – ١ ، هـ = ٢٧٠°

∴ $ع^٣$ = جتا ٢٧٠° + ت جا ٢٧٠°

⇐ ع_ك = $\left( جتا ( ٢٧٠° + ٣٦٠° ك ) + ت جا ( ٢٧٠° + ٣٦٠° ك ) \right)^{\frac{١}{٣}}$

= $جتا \frac{٢٧٠° + ٣٦٠° ك}{٣} + ت جا \frac{٢٧٠° + ٣٦٠° ك}{٣}$

بوضع ك = ٠

ع₀ = جتا ٩٠° + ت جا ٩٠° = ت

بوضع ك = ١ ، ع₁ = $جتا \frac{٢٧٠° + ٣٦٠°}{٣} + ت جا \frac{٢٧٠° + ٣٦٠°}{٣}$

= جتا ٢١٠° + ت جا ٢١٠°

= $– \frac{\sqrt{٣}}{٢} – \frac{١}{٢} ت$

وبوضع ك = ٢

ع₂ = $جتا \frac{٢٧٠° + ٧٢٠°}{٣} + ت جا \frac{٢٧٠° + ٧٢٠°}{٣}$

= جتا ٣٣٠° + ت جا ٣٣٠°

= $\frac{\sqrt{٣}}{٢} – \frac{١}{٢} ت$
