مثال (١) :

جد   د ص / د س   إذا كان :

(١) ص = ( ٥ س² + ٧ )^( ٣ / ٢ )

(٢) ص = جا س²

الحل  :

(١) ضع  ل = ٥ س² + ٧

إذن  ص = ل^( ٣ / ٢ )

عليه فإن  ص دالة في  ل   و ل دالة في  س  وهذا تركيب لدالة دالة .

∴   د ص / د س  =  د ص / د ل   .   د ل / د س

=   ٣ / ٢  ل^( ١ / ٢ ) ( ١٠ س )

=   ٣ / ٢  ( ٥ س² + ٧ )^( ١ / ٢ ) ( ١٠ س )

= ١٥ س ( ٥ س² – ٧ )^( ١ / ٢ )

(٢) ضع  ل = س²

∴ ص = جا ل

∴   د ص / د س  =  د ص / د ل   .   د ل / د س

= جتا ل ( ٢ س )

= ٢ س جتا س²
