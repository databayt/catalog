### تمرين ( ٣ – ٣ )

اكتب ما يلي  بصورة كسور جزئية :

(١) $\frac{٢ س + ٨}{س^{٣} – ٨}$

(٢) $\frac{٢س^{٣} + ٣}{( س^{٢} + ١ )^{٢}}$

(٣) $\frac{س^{٥}}{( س^{٢} + ٤ )^{٢}}$

(٤) $\frac{س^{٤} + ٥}{( س + ١ ) ( س^{٢} + ١ )}$

(٥) $\frac{س^{٣} + ١}{( ٤س^{٢} + ١ )^{٢}}$

(٦) $\frac{س – ٣}{( س – ١ )^{٢} ( س^{٢} + ٢ )}$

(٧) $\frac{٢ س^{٣} + س^{٢} + ٤}{(س^{٢} + ٤)^{٢}}$

(٨) $\frac{٤ س}{( س^{٢} + ١ )^{٣}}$

(٩) $\frac{٦س^{٣} – ١١ س^{٢} + ٥ س – ٤}{س ( س – ٢ ) ( س^{٢} + ١ )}$

(١٠) $\frac{س^{٤} + ٨ س^{٣} – س^{٢} + ٢ س + ١}{( س^{٢} + س ) ( س^{٢} + ١ )}$
