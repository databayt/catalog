## (٥) التكامل المحدد وتطبيقاته

### ( ٥ – ١ ) التكامل المحدد :

أفرض ص = د ( س ) داله معرفه في الفترة [ أ ، ب ] .

$\int$ د ( س ) د س = ر ( س ) ، ر $'$ ( س ) = د ( س )

$\int_{أ}^{ب}$ د ( س ) د س  = ر (ب)  –  ر ( أ )

يسمى هذا النوع من التكامل بالتكامل المحدد .

مثال (١) :

( أ ) $\int$[غير مقروء] ( س$^٣$ + س ) د س

(ب) $\int$[غير مقروء] ( س$^٢$ – ٢ ) د س

( أ ) $\int$[غير مقروء] ( س$^٣$ + س ) د س  =  [ $\frac{س^٤}{٤}$ + $\frac{س^٢}{٢}$ ] [غير مقروء]
