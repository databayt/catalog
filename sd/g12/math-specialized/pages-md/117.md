∴ ح ( ع ) = ح ( أ ∪ أ ′ )

وحيث أن أ ∩ أ ′ = ∅

∴ ح ( ع ) = ح ( أ ) + ح ( أ ′ ) مسلمة   (٣)

∴ ١ = ح ( أ ) + ح ( أ ′ ) مسلمة    (٢)

∴ ح ( أ ′ ) = ١ – ح ( أ )

نتيجة (٤– ١ ) :

ح ( ∅ ) = صفر .

البرهان :

ع ′ = ∅

لكن ح ( ع ′ ) = ١ – ح ( ع )

∴ ح ( ع ′ ) = ١ – ١ = صفر

∴ ح ( ∅ )= صفر

∵ أ ⊂ ب
