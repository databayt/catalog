$$\begin{array}{r}
س + ٣ \\
\hline
٢ س^٣ + ٧ س^٢ - ٢ س - ٢ \enspace \left| \enspace ٢ س^٢ + س - ٦ \right. \\
٢ س^٣ + س^٢ - ٦ س \\
\hline
٦ س^٢ + ٤ س - ٢ \\
٦ س^٢ + ٣ س - ١٨ \\
\hline
س + ١٦
\end{array}$$

∴ $\dfrac{٢ س^٣ + ٧ س^٢ - ٢ س - ٢}{٢س^٢ + س - ٦} = ( س + ٣ ) + \dfrac{س + ١٦}{٢ س^٢ + س - ٦}$

ثم نجزئ الكسر البحت إلى كسور جزئية بتحليل المقام أولاً :

$$\frac{س + ١٦}{٢ س^٢ + س - ٦} = \frac{س + ١٦}{( ٢ س - ٣ ) ( س + ٢ )}$$

ثم نتابع الحل كما في المثال السابق

$$\frac{س + ١٦}{( ٢ س - ٣ ) ( س + ٢ )} = \frac{أ}{٢س - ٣} + \frac{ب}{س + ٢}$$

∴ س + ١٦ = أ ( س + ٢ ) + ب ( ٢ س - ٣ )

بوضع س $= \dfrac{٣}{٢}$

$$\frac{٣}{٢} + ١٦ = أ \left( \frac{٣}{٢} + ٢ \right) + ب \left( ٢× \frac{٣}{٢} - ٣ \right)$$

∴ $\dfrac{٣٥}{٢} = \dfrac{٧ أ}{٢} \Leftarrow أ = ٥$
