### ( ٧ – ٢ ) بعض خواص الصورة القطبية للعدد المركب :

عرفنا سابقاً كيف يمكن إيجاد حاصل ضرب عددين مركبين في الصورة الديكارتية ، ولنر حاصل ضربهما عندما يكون العددان في الصورة القطبية ، فالعددان :

ع₁ = ر₁ ( جتا هـ₁ + ت جا هـ₁ )

ع₂ = ر₂ ( جتا هـ₂ + ت جا هـ₂ )

فان حاصل ضربهما :

ع₁ ع₂ = ر₁ ر₂ ( جتا هـ₁ + ت جا هـ₁ ) ( جتا هـ₂ + ت جا هـ₂ )

= ر₁ ر₂ ( جتا هـ₁ جتا هـ₂ + ت جتا هـ₁ جا هـ₂ + ت جا هـ₁ جتا هـ₂ – جا هـ₁ جا هـ₂ )

= ر₁ ر₂ [ جتا هـ₁ جتا هـ₂ – جا هـ₁ جا هـ₂ ] + ت [ جتا هـ₁ جا هـ₂ + جا هـ₁ جتا هـ₂ ]

= ر₁ ر₂ [ جتا ( هـ₁ + هـ₂ ) + ت جا ( هـ₁ + هـ₂ ) ]

أى أن حاصل ضرب عددين مركبين عدد مركب مقياسه ( طوله ) يساوى حاصل ضرب المقياسين وسعته ( زاويته ) تساوى مجموع الزاويتين .
