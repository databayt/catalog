( أ ) إذا كانت د″ ( س₁ ) > ٠ فإن ( س₁ ، د ( س₁ ) ) نهاية **صغرى محلية.**

(ب) إذا كانت د″ ( س₁ ) < ٠ فإن ( س₁ ، د ( س₁ ) ) نهاية **عظمى محلية.**

(ج) إذا كانت د″ ( س₁ ) = ٠ ، نحدد اشارة د′ ( س ) بجوار س₁ إلى اليسار وإلى اليمين . أى نتحصل على اشارة د′ ( س₁ + ه) ، د′( س₁ – ه ) . حيث ه > ٠ صغيرة صغراً كافياً ( أى متناهية في الصغر بحيث لا تتغير إشارة د′( س ) بين س₁ – ه و س₁ ولا بين س₁ و س₁ + ه)، فإذا كانت :

(١)د′ ( س₁ – ه ) سالبة و د′( س₁ + ه ) موجبة فان ( س₁ ، د ( س₁ ) ) **نهاية صغرى محلية** .

(٢)د′ ( س₁ – ه ) موجبة و د′ ( س₁ + ه ) سالبة فان ( س₁ ، د ( س₁ ) ) **نهاية عظمى  محلية** .
