وبصورة عامة نفترض أن :

ص  = د ( س )

فإذا كان  $\frac{د ص}{د س}$ = ر ( س )

فإننا نقول إن  ص  هى تكامل ر ( س ) بالنسبة لـ س وتكتب

$$ص = \int ر ( س ) د س$$

ويساوى ذلك د ( س ) + ث حيث  ث أى ثابت يسمى ثابت التكامل .

مثال (١) :

كامل ( جد تكامل ) الدالة ٣ س + ١ .

الحل :

$$\int ( ٣ س + ١ ) د س = \frac{٣}{٢} س^٢ + س + ث$$

لأن $\frac{د}{د س}$ ( $\frac{٣}{٢}$ $س^٢$ + س + ث )  =  ٣ س + ١

الآن لكل ن  ≠  –١

$$\frac{د}{د س} ( س^{ن+١} ) = ( ن + ١ ) س^ن$$

أو $$\frac{د}{د س} \left( \frac{س^{ن+١}}{ن + ١} \right) = س^ن$$
