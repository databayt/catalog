أ ∩ ( ب – أ ) = ∅  (حدثان متنافيان)

∴ ح (ب) = ح ( أ ) + ح ( ( ب – أ ) )   مسلمة (٣)

لكن ح ( ب – أ ) ≥ ٠ مسلمة (١)

∴ ح ( أ ) ≤ ح (ب)

نتيجة (٤– ٢ ) :

ح ( أ ) ≤ ١ حيث أ أي حادثة في ع

البرهان :

أ ⊂ ع

∴ ح (أ) ≤ ح ( ع )  ( نظرية ( ٦ – ٢ ) )

ح ( أ ) ≤ ١

من المسلمة (١) والنتيجة السابقة نستنتج أنه لأي حادثة أ فان ٠ ≤ ح ( أ ) ≤ ١

نظرية (٤– ٣ ) :

إذا كان أ ، ب حادثتين ، يكون :

ح ( أ ∪ ب) = ح ( أ ) + ح (ب) – ح (أ ∩ ب)

البرهان :

انظر الشكل (٤ – ٣ )

من الشكل نلاحظ أن :

أ ∪ ب = أ ∪ ( ب – أ )

وأن : أ ∩ ( ب – أ ) = ∅
