الحل :

النقطة أ ( ٣ ، ٤ ) تمثل العدد المركب ( ٣ + ٤ ت )

النقطة ب ( –٥ ، ٦ ) تمثل العدد المركب ( – ٥ + ٦ت )

النقطة ج ( –٢ ، ١٠ ) تمثل العدد المركب ( ٢– + ١٠ ت )

النقطة و ( ٠ ، ٠ ) تمثل العدد المركب صفر .

الشكل ( ٦ – ٣ ) تمثيل لهذه الأعداد :

![الشكل ( ٧ – ٣ )](pages/357.webp)

**الشكل ( ٧ – ٣ )**

- ج ( ٢– ، ١٠ )
- ب ( ٥– ، ٦ )
- أ
- ( ٣ ، ٤ )
- و

ميل و أ = $\frac{٤ – ٠}{٣ – ٠}$ = $\frac{٤}{٣}$

ميل ب ج = $\frac{١٠ – ٦}{٢– – ٥–}$ = $\frac{٤}{٣}$

∴ ميل و أ = ميل ب ج

∴ و أ // ب ج

ميل أ ج = $\frac{١٠ – ٤}{– ٢ – ٣}$ = $\frac{٦}{٥–}$ = $\frac{٦–}{٥}$

ميل و ب = $\frac{٦ – ٠}{٥– – ٠}$ = $\frac{٦ –}{٥}$

∴ ميل أ ج = ميل و ب

∴ أ ج // و ب

∴ الشكل و أ ج ب متوازي أضلاع

ملاحظة :

تلاحظ في المثال السابق أن :

٣ + ٤ ت مُثل بالنقطة أ ، ٥– + ٦ ت مُثل بالنقطة ب ، وأن مجموعهما
( ٣ + ٤ ت ) + ( ٥– + ٦ ت ) = ٢– + ١٠ ت يمثل بالنقطة ج .
