الحل :

( أ ) $$\int \left( س^٣ + \frac{١}{س^٣} \right) د س$$

$$= \int ( س^٣ + س^{–٣} ) د س$$

$$= \frac{١}{٤} س^٤ – \frac{١}{٢} س^{–٢} + ث$$

$$= \frac{س^٤}{٤} – \frac{١}{٢ س^٢} + ث$$

(ب) $$\int \left( \sqrt{س} + \frac{١}{\sqrt{س}} \right) د س$$

$$= \int \left( س^{\frac{١}{٢}} + س^{–\frac{١}{٢}} \right) د س$$

$$= \frac{س^{\frac{٣}{٢}}}{\frac{٣}{٢}} + \frac{س^{\frac{١}{٢}}}{\frac{١}{٢}} + ث$$

$$= \frac{٢}{٣} س^{\frac{٣}{٢}} + ٢ س^{\frac{١}{٢}} + ث$$

$$= \frac{٢}{٣} \sqrt{س^٣} + ٢ \sqrt{س} + ث$$
