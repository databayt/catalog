ولكن ب  = ( أ ∩ ب ) ∪ ( ب – أ )

( أ ∩ ب ) ∩ ( ب – أ ) = ∅

ح (ب) = ح ( أ ∩ ب ) + ح ( ب – أ )

ح ( ب – أ ) = ح ( ب ) – ح ( أ ∩ ب )   (٢)

من (١) ، (٢) نستنتج أن :

ح ( أ ∪ ب ) = ح ( أ ) + ح ( ب ) – ح ( أ ∩ ب)

مثال (١) :

إذا كان أ ، ب حدثين في تجربة عشوائية ، وكان :

ح ( أ ) = $\frac{٣}{٥}$   ،   ح (ب) = $\frac{١}{٤}$

ح ( أ ∩ ب) = $\frac{١}{٥}$   جد
