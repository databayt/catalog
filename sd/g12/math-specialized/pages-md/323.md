وبعد فك الاقواس :

= – ر(س₀) + ر(سن)    ∵ س₀ = أ ، سن = ب

∴ – ر(س₀) + ر(سن) = ر(ب) – ر( أ )

إذن : جن = ر ( ب ) – ر ( أ )

عليه فإن :

نها ن → ∞ جن = ر ( ب ) – ر ( أ )

الخلاصة :

إذا اردنا ايجاد محصلة المساحة المحصورة بين منحنى الداله ص = د (س) ومحور السينات بين س = أ و س = ب ، نتحصل أولاً على تكامل د (س) ، أى .

$\int$ د ( س ) د س = ر ( س )

ثم تكون محصلة المساحة :

ر ( ب ) – ر ( أ ) . ونعبر عن ذلك بـ :

$\int_{أ}^{ب}$ د ( س ) د س = ر ( ب ) – ر ( أ )

حيث ر′ ( س ) = د ( س ) .

وهذا هو التكامل المحدد الذى سبق لك التعرف عليه .
