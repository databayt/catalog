مثال (٣) :

حل المعادلة :

ع² + ( ٢ ت – ٣ ) ع + ( ٥ – ت ) = ٠

الحل :

نلاحظ أن : أ = ١     ، ب = ٢ ت – ٣   ،   جـ = ٥ – ت

∴ ع =  $\frac{– ( ٢ ت – ٣ ) ± \sqrt{( ٢ ت – ٣ )² – ٤ × ١ ( ٥ – ت )}}{٢}$

=  $\frac{( ٣ – ٢ ت ) ± \sqrt{– ١٥ – ٨ ت}}{٢}$

ولا يجاد $\sqrt{– ١٥ – ٨ ت}$ نفرض أن :

( س + ص ت )² = ١٥– – ٨ ت

ومنه س² – ص² = ١٥–

٢ س ص = ٨–

∴ ص = $\frac{– ٤}{س}$

∴ س² – $\frac{١٦}{س²}$  =  ١٥–

س⁴ – ١٦ = ١٥– س² ⇐ س⁴ + ١٥ س² – ١٦ = ٠

⇐ ( س² + ١٦ ) ( س² – ١ ) = ٠

⇐ س² – ١ = ٠ ⇐ س = ± ١

∴ ص = ∓ ٤ ( إشارة س تخالف إشارة ص لأن ٢ س ص سالباً )

∴ الجذران التربيعيان للمقدار  ١٥– – ٨ ت  هما ± ( ١ – ٤ ت ) ومنه
