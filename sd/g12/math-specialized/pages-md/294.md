### تمرين ( ٤ – ١ )

(١) جد التكاملات الآتية :

( أ ) $\int س^٧ د س$

(ب) $\int \frac{س^٣ - ١}{س^٢} د س$

( ج ) $\int \left( ن^٢ + \frac{١}{ن} \right) د ن$

( د ) $\int ( ١ - ٣ س ) ( ١ + س ) د س$

( هـ ) $\int ظا^٢ س د س$

( و ) $\int جا^٢ س د س$

( تلميح : جتا ٢ س = ١ – ٢ جا$^٢$ س )
