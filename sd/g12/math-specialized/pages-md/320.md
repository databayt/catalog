∵ ص = د ( س ) فإن القيمة العددية لأطوال الأشكال (المستطيلة ) ، الشكل ( ٥ – ٣ ) هى د ( هـ₁ ) ، د ( هـ₂ ) ... ، د ( هـك ) ، ... ، د ( هـن ) على التوالى .

أما عرض هذه الاشكال فهو Δ س

∴ مساحة الشكل الأول = د ( هـ₁ ) × Δ س

مساحة الشكل الثانى = د ( هـ₂ ) × Δ س

وهكذا

فإذا أردنا ايجاد المساحة الكلية بين المنحنى ومحور السينات في الفترة [ أ ، ب ] فإننا نقوم بجمع مساحة كل الأشكال السابقة . فإذا أفترضنا أن جن تمثل المساحة الكلية فإن :

جن = د ( هـ₁ ) Δ س + د ( هـ₂ ) Δ س + .... + د ( هـن ) Δ س ...... (١)

لاحظ أنه كلما اقتربت Δ س من الصفر أقتربت مساحة المستطيلات من المساحة المحصورة بين منحنى الدالة ص = د ( س ) والمحور السينى من س = أ إلى س = ب .
