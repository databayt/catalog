مثال (٣) : جد : نها (س → ∞) ( س⁴ + ٥ س – ١ ) / ( س³ + ٣ )

الحل :

بالقسمة على أعلى قوة للمتغير س في المقام نحصل على :

نها (س → ∞) ( س⁴ + ٥ س – ١ ) / ( س³ + ٣ ) = نها (س → ∞) ( س + ٥/س² – ١/س³ ) / ( ١ + ٣/س³ ) = ∞

(ب) الحالة الثانية والتي يكون ناتج التعويض فيها صفر/صفر نحلل البسط والمقام

لاستخراج العامل المشترك (س – أ) واختصار هذا العامل المشترك ثم التعويض في المقدار الناتج عن س بالقيمة أ لنحصل على النهاية المطلوبة كما في الأمثلة التالية

مثال (٤) : جد : نها (س → ٤) ( س² – ٢س – ٨ ) / ( س – ٤ )

الحل :

عند التعويض المباشر نحصل على صفر/صفر وهى قيمة غير معرفة

ولكن :

( س² – ٢س – ٨ ) / ( س – ٤ ) = ( ~~( س – ٤ )~~ ( س + ٢ ) ) / ~~( س – ٤ )~~

= س + ٢ ، س ≠ ٤
