( أ )  التكامل بالتعويض :

لإيجاد التكامل

$$\int (٥ س + ٣)^٢ د س$$

نكتب ( ٥ س + ٣ )$^٢$ = ٢٥ س$^٢$ + ٣٠ س + ٩

ثم نجر التكامل المطابق

$$\int (٢٥ س^٢ + ٣٠ س + ٩) د س$$

$$= \frac{٢٥}{٣} س^٣ + ١٥ س^٢ + ٩س + ث$$

لكن إذا حاولنا نفس الطريقة لايجاد التكامل $\int (٥ س + ٣)^{١٠} د س$ مثلاً فإن ذلك يستغرق وقتاً طويلاً لفك القوس ( ٥ س + ٣ )$^{١٠}$ بذات الحدين ثم نتحمل عناء إجراء التكامل لــ ١١ حد .

الآن إذا عوضنا ع = ٥ س + ٣ فإن :

$$\frac{د ع}{د س} = ٥$$

$$\therefore \ \ د س \equiv \frac{د ع}{٥}$$

عليه يتحول التكامل إلى :

$$\int (٥ س + ٣)^{١٠} د س \equiv \int ع^{١٠} \frac{د ع}{٥}$$

$$= \frac{١}{٥} \int ع^{١٠} د ع = \frac{١}{٥} \frac{ع^{١١}}{١١} + ث$$

$$= \frac{(٥س + ٣)^{١١}}{٥٥} + ث$$
