مثال (٢) :

جد   د ص / د س   إذا كان  ص² + س² = ٤

الحل :

٢ ص    د ص / د س   + ٢ س = صفر

∴    د ص / د س   =  –  س / ص

مثال (٣) :

جد   د ص / د س   إذا كان   ص = ظا⁻¹ س ( الزاوية التى ظلها  س )

الحل :

إذا كانت  ص = ظا⁻¹ س فإن  س = ظا ص

بتفاضل الطرفين بالنسبة لــ س نحصل على :

١ = قا² ص    د ص / د س

∴    د ص / د س   =   ١ / قا² ص

لإيجاد ذلك بدلالة  س ، لاحظ أن :

قا² ص  =  ١ + ظا² ص  =  ١ + س²

∴    د ص / د س   =   ١ / ( ١ + س² )
