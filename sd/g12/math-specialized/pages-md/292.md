**جدول ( ٤ – ١ )**

مثال (٤) :

جد :

( أ ) $\int$ جا ٧ س د س

(ب) $\int$ جا ٢س جتا س د س

الحل :

( أ )  من الجدول :

$$\int جا ٧س د س = – \frac{١}{٧} جتا ٧ س + ث$$

(ب) جا٢س جتا س ليست مع الصيغ الأساسية ولكن

$$جا ٢س جتا س = \frac{١}{٢} [ جا ٣ س + جا س ]$$

إذن :   $\int جا٢س جتا س د س = \int \left( \frac{١}{٢} جا ٣ س + \frac{١}{٢} جا س \right) د س$
