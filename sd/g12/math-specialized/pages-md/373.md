∴ ر₀ = $ر^{\frac{١}{ن}}$ ، هـ₀ = $\frac{هـ}{ن}$ . عليه فإن :

ع₀ = $ر^{\frac{١}{ن}} \left[ جتا \frac{هـ}{ن} + ت جا \frac{هـ}{ن} \right]$

لإيجاد ع₁ نأخذ ع = ر [ جتا ( هـ + ٢π ) + ت جا ( هـ + ٢π ) ]
أو ر₁$^ن$ [ جتا ن هـ₁ + ت جا ن هـ₁ ] = ر [ جتا ( هـ + ٢π ) + ت جا ( هـ + ٢π ) ]
أو [ ر₁$^ن$ ، ن هـ₁ ] = [ ر ، هـ + ٢π ]

∴ ر₁ = $ر^{\frac{١}{ن}}$ ، هـ₁ = $\frac{هـ + ٢π}{ن}$ . عليه فإن :

ر₁ = $ر^{\frac{١}{ن}} \left[ جتا \frac{هـ + ٢π}{ن} + ت جا \frac{هـ + ٢π}{ن} \right]$

أما بالنسبة لـــ ع₂ وبأخذ ع = ر [ جتا ( هـ + ٢ × ٢π ) + ت جا ( هـ + ٢ × ٢π ) ] ، وبإتباع نفس الخطوات السابقة نحصل على :

∴ ع₂ = $ر^{\frac{١}{ن}} \left[ جتا \frac{هـ + ٢ × ٢π}{ن} + ت جا \frac{هـ + ٢ × ٢π}{ن} \right]$

وبصورة عامة :

ع_ك = $ر^{\frac{١}{ن}} \left[ جتا \frac{هـ + ك × ٢π}{ن} + ت جا \frac{هـ + ك × ٢π}{ن} \right]$

ك = ٠ ، ١ ، ٢ ، ........ ، ن – ١ .
