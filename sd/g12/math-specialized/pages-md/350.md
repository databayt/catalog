(٣) بين أن المستقيم ل : $س + ٢ ص = ١٢$ مماس للدائرة

ن : $س^٢ + ص^٢ - ٦ س = ٤ ص - ٨$

(٤) جد معادلة الدائرة التى مركزها نقطة الأصل وتمس المستقيم  ل :

$$٢ س = ٣ ص + ١٣$$

(٥) جد معادلة الدائرة التى مركزها ( ١ ، ٢ ) وتمس المستقيم

ل : $٤ س - ٣ ص + ١٢ = ٠$

### ( ٦ – ٥ ) طول المماس المرسوم للدائرة من نقطة خارجها :

نفرض أن المطلوب ايجاد طول المماس المرسوم للدائرة :

$$س^٢ + ص^٢ + ٢ ل س + ٢ ك ص + ج = ٠$$

من النقطة  ب ( س₁ ، ص₁ ) . فإذا كانت  م مركز الدائرة  ن نقطة التماس  شكل  ( ٦ – ٤ ) .

![الشكل ( ٦ – ٤ )](pages/350.webp)

**الشكل ( ٦ – ٤ )**

- ب
- ( س₁ ، ص₁ )
- ن
- م ( -ل ، -ك )

∴ نجد أن :

$$\overline{ب ن}^٢ = \overline{ب م}^٢ - \overline{م ن}^٢$$

∴ $\overline{ب ن}^٢ = ( س₁ + ل )^٢ + ( ص₁ + ك )^٢ - \overline{م ن}^٢$

وبما أن $\overline{م ن}^٢ = نق^٢ = ل^٢ + ك^٢ - ج$
