(١٣) ص = جا س + جتا س

(١٤) ص = س³ جا س

(١٥) ص  =  ( ٣ + ٤ جا س ) / ( ٤ + ٣ جا س )

(١٦)  ص  =  ( ١ – جا س ) / ( ١ + جتا س )

(١٧)  إذا كان ص = جا س جتا س أثبت أن  د ص / د س  = جتا ٢ س

### ( ٢ – ٥ ) دالة الدالة :

لتكن ص = د ( ل ) دالة في المتغير  ل  ، و ل = ر ( س ) دالة في المتغير  س . عليه فان

د ص / د س  =  د ص / د ل  .  د ل / د س

البرهان :

إذا تغيرت  س إلى س + Δ س فان  ل  تتغير إلى  ل + Δ ل  وتبعاً لذلك تتغير  ص إلى ص + Δ ص .

Δ ص / Δ س  =  Δ ص / Δ ل  .  Δ ل / Δ س

∴     د ص / د س   =  نها   Δ ص / Δ س
                        Δ س → ٠

=  نها   Δ ص / Δ ل   .  نها   Δ ل / Δ س     ( لأن Δ ل → ٠ عندما Δ س → ٠ )
Δ ل → ٠              Δ س → ٠

=   د ص / د ل   .   د ل / د س
