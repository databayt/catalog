**الشكل ( ٦ – ٣ )**

- جـ
- ص
- م
- ( – ل ، – ك )
- أ
- ( س′ ، ص′ )
- س
- و
- د

وبما أن المماس  ج د   ⊥   أ م

∴ ميل المماس  ج د  =  – $\frac{س′ + ل}{ص′ + ك}$

∴ معادلة المماس :

ص – ص′  =  – $\frac{س′ + ل}{ص′ + ك}$ ( س – س′ )

⇐  ( ص – ص′ ) ( ص′ + ك ) = – ( س′ + ل ) ( س – س′ )

⇐  ( ص – ص′ ) ( ص′ + ك ) + ( س′ + ل ) ( س – س′ ) = ٠

⇐  ص ص′ + ك ص – ص′² – ك ص′ + س س′ + ل س – س′² – ل س′ = ٠

⇐  س س′ + ص ص′ + ل س + ك ص = س′² + ص′² + ل س′ + ك ص′

وباضافة المقدار ل س′ + ك ص′ + جـ للطرفين ينتج :

س س′ + ص ص′ + ل ( س + س′ ) + ك ( ص + ص′ ) + جـ = س′²
+ ص′² + ٢ ل س′ + ٢ ك ص′ + جـ

وبما أن النقطة  ( س′ ، ص′ ) تقع على الدائرة ، فإنها تحقق معادلتها .
