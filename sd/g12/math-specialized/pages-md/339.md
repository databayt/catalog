∴ المعادلة تمثل دائرة  .

مركزها  ( – ل ، – ك ) = ( –٢ ، –٣ )

نق = √( ل² + ك² – ج )  =  √٢٥ = ٥ وحدات

مثال (٢) :

جد المركز ونصف القطر للدائرة التى معادلتها :

٤ س² + ٤ ص² + ٤ س + ٢٤ ص + ٩  =  ٠

الحل :

نقسم أولاً على ٤ لجعل معامل س² = معامل ص² = ١

س² + ص² + س + ٦ ص  + $\frac{٩}{٤}$ = ٠

∴ ٢ ل = ١  ⇐  ل = $\frac{١}{٢}$

٢ ك = ٦  ⇐  ك = ٣

∴ المركز = ( – $\frac{١}{٢}$ ، ⁻٣ )

نق = √( ( – $\frac{١}{٢}$ )² + ( –٣ )² – $\frac{٩}{٤}$ )

= √( $\frac{١}{٤}$ + ٩ – $\frac{٩}{٤}$ )  =  √( $\frac{١ + ٣٦ – ٩}{٤}$ )  =  √( $\frac{٢٨}{٤}$ ) = √٧
