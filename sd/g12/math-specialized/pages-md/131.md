مثال (٣) :

فصل به أربعون طالباً صنفوا وفقاً لهواياتهم على النحو التالي :

|  | من هواة الرياضة | ليس من هواة الرياضة |
| --- | --- | --- |
| من هواة الموسيقا | ٤ | ١٠ |
| ليس من هواة الموسيقا | ٢٠ | ٦ |

اخترنا طالباً بصورة عشوائية ، ولتكن أ : حادثة أنه من هواة الموسيقا ، ب : حادثة أنه من هواة الرياضة أحسب :

ح ( أ )      ،      ح ( ب )      ،      ح ( أ ∩ ب ) ،

ح ( أ ∪ ب )   ،   ح ( أ ′ )   ،   ح ( أ ′ ∩ ب )

الحل :

إذا تأملنا الجدول نجد أن :

١٤ طالباً يهوى الموسيقا

∴ ح ( أ )  =  $\frac{١٤}{٤٠}$ = $\frac{٧}{٢٠}$

وبصورة مماثلة ح ( ب )  =  $\frac{٢٤}{٤٠}$ = $\frac{٣}{٥}$

ولحساب ح ( أ ∩ ب ) نلاحظ أن ٤ طلاب فقط من هواة الرياضة والموسيقا معاً

فيكون ح ( أ ∩ ب ) = $\frac{٤}{٤٠}$  =  $\frac{١}{١٠}$

ولحساب ح ( أ ∪ ب ) نطبق قانون الاحتمال الكلى فنجد :

ح ( أ ∪ ب ) = $\frac{٧}{٢٠}$ + $\frac{٣}{٥}$ – $\frac{١}{١٠}$ = $\frac{٧ + ١٢ – ٢}{٢٠}$  =  $\frac{١٧}{٢٠}$
