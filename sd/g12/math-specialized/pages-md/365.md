فإن طول $\frac{ع₁}{ع₂}$ يساوى حاصل قسمة طول ع₁ على طول ع₂ وأن زاوية حاصل القسمة تساوى حاصل طرح زاوية ع₂ من زاوية ع₁ .

فإذا كان ع₁ = [ ٨ ، ٦٠° ] ، ع₂ [ ٤ ، ٤٥° ]

$$\frac{ع₁}{ع₂} = [ \frac{٨}{٤} ، ( ٦٠° – ٤٥° ) ] = [ ٢ ، ١٥° ]$$

مثال (١) :

جد قيمة ما يأتي :

(أ) ٨ ( جتا $\frac{\pi}{٣}$ + ت جا $\frac{\pi}{٣}$ ) × ٦ ( جتا $\frac{\pi}{٤}$ + ت جا $\frac{\pi}{٤}$ )

(ب) ١٢ ( جتا ٢٤٠° + ت جا ٢٤٠° ) ÷ ٦ ( جتا ٣٠° + ت جا ٣٠° )

الحل :

(أ) ٨ ( جتا $\frac{\pi}{٣}$ + ت جا $\frac{\pi}{٣}$ ) × ٦ ( جتا $\frac{\pi}{٤}$ + ت جا $\frac{\pi}{٤}$ )

= ٤٨ جتا ( $\frac{\pi}{٣}$ + $\frac{\pi}{٤}$ ) + ت جا ( $\frac{\pi}{٣}$ + $\frac{\pi}{٤}$ )

= ٤٨ ( جتا $\frac{٧\pi}{١٢}$ + ت جا $\frac{٧\pi}{١٢}$ )

(ب) ١٢ ( جتا ٢٤٠° + ت جا ٢٤٠° ) ÷ ٦ ( جتا ٣٠° + ت جا ٣٠° )

= $\frac{١٢}{٦}$ [ جتا ( ٢٤٠° – ٣٠° ) + ت جا ( ٢٤٠° – ٣٠° ) ]

= ٢ ( جتا ٢١٠° + ت جا ٢١٠° )
