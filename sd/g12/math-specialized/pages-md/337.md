### ( ٦ – ٢ ) الصورة العامة لمعادلة الدائرة :

فيما سبق وجدنا أن معادلة الدائرة التى مركزها النقطة  م ( د ، هـ ) ونصف قطرها نق هى :

( س – د )² + ( ص – هـ )² = نق²  حيث د ، هـ ∈ ح    (١)

وبازالة الأقواس تصبح المعادلة (١) :

س² – ٢د س + د² + ص² – ٢هـ ص + هـ² = نق²

وبوضع  د = – ل ، هـ = – ك

∴ س² + ٢ ل س + ل² + ص² + ٢ ك ص + ك² – نق² = ٠

أى :

س² + ص² + ٢ ل س + ٢ ك ص + ل² + ك² – نق² = ٠

وبوضع  ل² + ك² – نق² = ج

س² + ص² + ٢ ل س + ٢ ك ص + ج = ٠    (٢)

⇐ ل² + ك² – ج = نق²
