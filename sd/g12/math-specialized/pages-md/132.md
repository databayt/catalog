ولحساب ح ( أ ′ ) : أي احتمال ألا يكون من هواة الموسيقا يمكن تطبيق النظرية    ح ( أ′) = ١ – ح ( أ )

= ١  –  $\frac{٧}{٢٠}$ = $\frac{١٣}{٢٠}$

أو نحسبه بايجاد عدد الطلاب الذين ليسوا من هواة الموسيقا من الجدول وهــم ٢٦ فيكون ح ( أ′)  =  $\frac{٢٦}{٤٠}$ = $\frac{١٣}{٢٠}$

ولحساب ح ( أ ′ ∩ ب ) وهو احتمال أن يكون الطالب ليس من هواة الموسيقــا ومن هواة الرياضة وعددهم ٢٠ فيكون  ح ( أ ′ ∩ ب ) =  $\frac{٢٠}{٤٠}$ = $\frac{١}{٢}$

### تمرين ( ٤ – ٨ )

(١) لنفرض أن ح ( أ ) =  ٠,٢   ،   ح ( ب ) = ٠,٣   ،   ح ( أ ∪ ب ) = ٠,٤

أحسب : (١) احتمال وقوع أ و ب

(٢) احتمال حدوث واحدة منها دون الأخرى .

(٣) احتمال عدم وقوع أي منها .

(٢) إذا كان ح ( أ ) =٠,٢ ، ح ( ب ) = ٠,٤ ، ح ( أ ∪ ب ) = ٠,٥ أحسب :
