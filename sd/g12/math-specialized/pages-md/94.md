إذن :

$$\frac{٣ س + ٥}{س^٣ - س^٢ - س + ١} = \frac{أ}{س + ١} + \frac{ب}{س - ١} + \frac{جـ}{(س - ١)^٢}$$

لاحظ أن معامل المقام ( س – ١ )² قد قابله كسرين جزئيين هما :

$\dfrac{ب}{س - ١}$ و $\dfrac{جـ}{(س - ١)^٢}$ وبالتالي :

$$٣ س + ٥ = أ (س - ١)^٢ + ب (س + ١) (س - ١) + جـ (س + ١)$$

إذا وضعنا س = ١ نجد أن :

٨ = ٢ جـ ⇐ جـ = ٤

وإذا وضعنا س = ⁻١ نجد أن :

٢ = ٤ أ ⇐ $أ = \dfrac{١}{٢}$

ولتعيين الثوابت الأخرى استخدم  أي قيمة أخرى لـــ س مثلاً س = ٠

فنجد أن :

٥ = أ – ب + جـ ومنه

$$٥ = \frac{١}{٢} - ب + ٤ \Leftarrow ب = \frac{⁻١}{٢}$$

إذن :

$$\frac{٣ س + ٥}{س^٣ - س^٢ - س + ١} = \frac{١}{٢ (س + ١)} - \frac{١}{٢(س -١)} + \frac{٤}{(س - ١)^٢}$$
