### ( ٣ – ١ ) تطبيقات على الهندسة التحليلية :

سبق أن أشرنا في البند ( ٢ – ٢ ) إلى المعنى الهندسى لمشتقه الدالة ص = د ( س ) . فميل المماس عند النقطة ( س₁ ، د ( س₁ ) ) يساوى د ′ ( س₁ ) هذا يساعد كثيراً في حل بعض المسائل في الهندسة التى سبق أن اشرنا إلى بعضها في تمارين سابقة .

مثال (١) :

جد معادلة المماس لمنحنى الداله ص = ١/س عند النقطة ( ١ ، ١ ) .

الحل :

د ص/د س = – ١/س²

∴ ميل المماس عند س = ١ يساوى – ١

∵ ص – ص₁ = م ( س – س₁ ) إذن معادلة المماس هى :

ص – ١ = – ١ ( س – ١ )

أو س + ص – ٢ = صفر

مثال (٢) :

جد معادلة المماس ومعادلة العمودى على المماس لمنحنى الدالة :

ص = س² – س + ١ عند س = ٠

الحل :

د ص/د س = ٢ س – ١

∴ ميل المماس عند النقطة ( ٠ ، ١ ) يساوى – ١

∴ معادلة المماس :

ص – ص₁ =م ( س – س₁ )

ص – ١ = – ١ ( س – ٠ )

⇐ ص + س – ١ = ٠

ميل العمودى على المماس = ١
