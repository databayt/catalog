ب = { ٢ ، ٤ ، ٦ }

∴ أ ∩ ب = { ٦ }

∴ ح ( أ ∪ ب ) = ح ( أ ) + ح ( ب )  –  ح ( أ ∩ ب )

= $\frac{٢}{٦}$ + $\frac{٣}{٦}$ – $\frac{١}{٦}$ = $\frac{٤}{٦}$ = $\frac{٢}{٣}$

مثال (٢) :

القى حجرا نرد متمايزان مرة واحدة ، فما احتمال أن يكون مجموع النقط على السطح العلوي لهما ٤ أو ٩ ؟

الحل :

عدد عناصر فضاء العينة ع = ٣٦

نفرض أن أ هى حادثة أن يكون المجموع ٤

∴ أ = { ( ١ ، ٣ ) ، ( ٢ ، ٢ ) ، ( ٣ ، ١ ) }

∴ عدد عناصر أ = ٣

نفرض أن ب حادثة أن يكون المجموع ٩

∴ ب = { ( ٣ ، ٦ ) ، ( ٤ ، ٥ ) ، ( ٥ ، ٤ ) ، ( ٦ ، ٣ ) }

∴ عدد عناصر ب = ٤

أ ∩ ب = ∅

∴ ح ( أ ∪ ب ) = ح ( أ ) + ح ( ب)

= $\frac{٣}{٣٦}$ + $\frac{٤}{٣٦}$ = $\frac{٧}{٣٦}$
