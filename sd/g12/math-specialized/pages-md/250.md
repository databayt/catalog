ماذا تفعل لإيجاد   د ص / د س   بالنظر لــ ص كداله في المتغير  س ، في مثل قاعدة هذه الدالة.

لنفرض أن ص = د( س ) ، عليه فان أى داله ر ( ص ) في  ص  يمكن النظر لها كداله في  س  وباستخدام قاعدة دالة الدالة فإن :

د / د س  ( ر ( ص ) )  =  ر ′ ( ص )   د ص / د س

إذن يمكن كتابة :

د / د س   ص^ن  =  ن ص^(ن – ١)   د ص / د س

د / د س   جا ص  =  جتا ص   د ص / د س

وهكذا  .

مثال (١) :

جد   د ص / د س   إذا كان  س + ص² = ٥ س ص

الحل :

تفاضل كل الحدود بالنسبة لــ س لنحصل على :

١ + ٢ ص   د ص / د س   =  ٥ [ س   د ص / د س   + ص ]

إذن :

د ص / د س   [ ٢ ص – ٥ س ]  =  ٥ ص – ١

∴    د ص / د س   =  ( ٥ ص – ١ ) / ( ٢ ص – ٥ س )
