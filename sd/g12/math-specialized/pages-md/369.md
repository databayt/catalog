مثال (٢) :

إذا كان  ع = ١ + ت فاحسب ع¹⁰

الحل :

ع = ( ١ + ت )   ⇐   ر = $\sqrt{٢}$

∴ ع = $\sqrt{٢}$ ( $\frac{١}{\sqrt{٢}}$ + $\frac{١}{\sqrt{٢}}$ ت )

ع = $\sqrt{٢}$ ( جتا $\frac{\pi}{٤}$ + ت جا $\frac{\pi}{٤}$ ) = [ $\sqrt{٢}$ ، $\frac{\pi}{٤}$ ]

∴ ع¹⁰ = [ ( $\sqrt{٢}$ )¹⁰ ، $\frac{١٠\pi}{٤}$ ] = [ ٣٢ ، $\frac{٥\pi}{٢}$ ] = [ ٣٢ ، $\frac{\pi}{٢}$ ]

∴ ع¹⁰ = ٣٢ ( جتا $\frac{\pi}{٢}$ + ت جا $\frac{\pi}{٢}$ )  =  ٣٢ ت
