مثال (٢) :

أحسب  $ω^{٣٢}$ ، $ω^{–٤١}$

الحل :

$ω^{٣٢}$ = $ω^{٣٠}$ . $ω^٢$ = $(ω^٣)^{١٠}$ . $ω^٢$ = $١^{١٠}$ $ω^٢$ = $ω^٢$

$ω^{–٤١}$ = $ω^{–٤٢}$ . ω = $(ω^٣)^{–١٤}$ . ω = $١^{–١٤}$ . ω = ω

وبصورة عامة :

$ω^{٣ن + ر}$ = $ω^ر$

حيث  ن عدد صحيح ، ر = ٠ ، ١ ، ٢

مثال (٣) :

اثبت أن :

( ١ – $ω^٢$ + $ω^٤$ ) ( ١ + $ω^٢$ – $ω^٤$ ) = ٤

الحل :

الطرف الأيمن  :

( ١ – $ω^٢$ + $ω^٤$ ) ( ١ + $ω^٢$ – $ω^٤$ )

= ( ١ – $ω^٢$ + ω ) ( ١ + $ω^٢$ – ω ) ( لأن $ω^٤$ = ω )

= ( ١ + ω – $ω^٢$ ) ( ١ + $ω^٢$ – ω )

= ( – $ω^٢$ – $ω^٢$ ) ( – ω – ω )

لأن ١ + ω = – $ω^٢$ ، ١ + $ω^٢$ = – ω

= ( –٢$ω^٢$ ) ( –٢ω ) = ٤$ω^٣$ = ٤ × ١

=  ٤   الطرف الأيسر
