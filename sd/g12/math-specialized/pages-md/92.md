وبوضع س = ⁻٢

⁻٢ + ١٦ = ب ( ⁻٤ - ٣ )

فيكون : ⁻٢ = ب ⇐ ⁻٧ ب = ١٤

$$\frac{٢ س^٣ + ٧س^٢ - ٢س - ٢}{٢ س^٢ + س - ٦} = ( س + ٣ ) + \frac{٥}{٢س - ٣} - \frac{٢}{س + ٢}$$

**مثال (٣) :**

جزئ الكسر التالي إلى كسور جزئية :

$$\frac{س + ١}{س^٣ + س^٢ - ٦ س}$$

**الحل :**

$$\frac{س + ١}{س^٣ + س^٢ - ٦ س} = \frac{س + ١}{س ( س + ٣ ) ( س - ٢ )}$$

$$= \frac{أ}{س} + \frac{ب}{س + ٣} + \frac{جـ}{س - ٢}$$

∴ س + ١ = أ (س + ٣) (س - ٢) + ب س (س - ٢) + جـ س (س + ٣)

بوضع س = ٠

١ = ⁻٦ أ ⇐ $أ = - \dfrac{١}{٦}$

بوضع س = ٢

٣ = ١٠ جـ ⇐ $جـ = \dfrac{٣}{١٠}$

بوضع س = ⁻٣

⁻٢ = ١٥ ب ⇐ $ب = \dfrac{⁻٢}{١٥}$

∴ $\dfrac{س + ١}{س^٣ + س^٢ - ٦ س} = - \dfrac{١}{٦ س} - \dfrac{٢}{١٥ ( س + ٣ )} + \dfrac{٣}{١٠(س - ٢)}$
