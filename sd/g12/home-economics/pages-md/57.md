**مخطط (٢ – ٣ ) : الأسباب التي تؤدى إلى نقص فيتامين ( أ ) .**

- نقص فيتامين ( أ )
- نوع الأسباب :
- مباشرة
- خلل في استقلاب فيتامين ( أ )
- عدم كفاية فيتامين ( أ )
- كامنة
- الأمراض المعدية : – الفيروسية – الحصبة – الإسهال – والأمراض التنفسية – الطفيليات
- انخفاض شعبية / الخضروات خضراء الأوراق
- – ضعف إنتاج الخضروات خضراء الأوراق / والفاكهة الصفراء / البرتقالية اللون وزيت النخيل ( الأحمر ) – فيتامين (ج)
- أ
- أساسية
- نقص الوعي بالأغذية الغنية بفيتامين (أ) وأهميتها
- ضعف التشديد على التوسع الزراعي ، عدم وجود سياسة للأغذية الغنية بفيتامين (أ)
- نقص المياه
- ضعف الخدمات الصحية : عدم توافر المعالجة بالامهاء الفموي / خدمات التمنيع
- ضعف البيئة : – تلوث المياه – سوء الإصحاح – التصحيح الغذائي
- جهل الوالدين بالرعاية الغذائية
- الفقر
