**تدريب (3)**

قبل أن نستكمل ما بدأناه عن التطعيم، لنتوقف هنا لحظة لحل هذا التدريب:

- ضع علامة (✓) أمام العبارة الصحيحة وعلامة ( X ) أمام العبارة الخطأ:

1. التكاثر بالعقل يُعطي نباتات تشبه أصولها لحد كبير. ( )
2. التكاثر بالتطعيم ينتج نباتاً له ميزات النبات الأصل فقط. ( )
3. الفرع المرقد ينتج غذاءه بنفسه في أسابيع الترقيد الأولى. ( )
4. تعامل نهاية العقلة المقطوعة بالأوكسين لتحفيز نمو الجذور. ( )
5. شمع التطعيم يعمل على حماية جرح النبات من الآفات ومنع دخول الهواء. ( )
6. في التطعيم باللصق يستخدم أصل مزروع في التربة. ( )
7. يغطى جرح النبات المرقد هوائياً، بقطعة قماش أو قطن مبلل بالماء. ( )

وبرغم اختلاف الطرق المستعملة في عملية التطعيم تبقى أساسيات العملية ثابتة نوردها فيما يلي:

- عند إجراء عملية التطعيم يوضع جزء من نبات يسمى الطعم Scion على نبات آخر يسمى الأصل Stock بحيث يلتصق النسيج النامي (الكامبيوم) Cambium لكل منهما مع الآخر. يكوّن كلاهما خشباً ولحاءً جديدين ويلتحما معاً كما لو كانا نباتاً واحداً. وفي الغالب يغمس الأصل أو الطعم أو كلاهما قبل إجراء التطعيم في محلول الأوكسين، وهو هرمون يحفز انقسام الخلايا والالتحام المبكر، مما يتيح فرصة أكبر لنجاح عملية التطعيم.
