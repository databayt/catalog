**تدريب (8)**

زاوج بين العضو في القائمة (أ) مع مايناسبه من وظيفة في القائمة (ب):

| القائمة (أ)                 | القائمة (ب)                                       |
| --------------------------- | ------------------------------------------------- |
| الممصات في رأس التينيا      | حمل الحيوانات المنوية من الخصية إلى الوعاء الناقل |
| الكيس المنوي في التينيا     | حفظ البيض حتى موسم التناسُل                       |
| الرحم في التينيا            | تخزين الحيوانات المنوية                           |
| الوعاء المنوي في التينيا    | نقل البول والحيوانات المنوية إلى الخارج           |
| الحويصلة المنوية في الضفدعة | التعلق بجدار الإمعاء                              |
| الحالب في الضفدعة           | تخزين الحيوانات المنوية                           |
| كيس البيض في الضفدعة        | الإخصاب                                           |
|                             | استقبال البيض المُخصَّب وحفظه                     |
