من الأمثلة السابقة يمكننا التوصل إلى النظرية التالية :

**نظرية (١ - ١ ) :**

(١) إذا كان د ( س ) = جـ حيث جـ عدد حقيقى فإن $نها_{س ← أ}$ د ( س ) = جـ لأى عدد حقيقى أ .

(٢) إذا كان ق ( س ) = س

فإن $نها_{س ← أ}$ ق ( س ) = أ لآى عدد حقيقى أ

(٣) وإذا كان ه ( س ) = م س + جـ فإن

$نها_{س ← أ}$ ه ( س ) = م أ + جـ

**مثال (٣) :**

إذا كان ه ( س ) = س + ٥ جد :

( أ ) ٣ ه ( س ) ، (ب) $نها_{س ← ١}$ ٣ ه ( س ) ، (جـ) ٣ $نها_{س ← ١}$ ه ( س )

**الحل :**

( أ ) ٣ ه ( س ) = ٣ ( س + ٥ ) = ٣ س + ١٥

(ب) $نها_{س ← ١}$ ٣ ه ( س ) = $نها_{س ← ١}$ ( ٣ س + ١٥ ) = ١٨

(جـ) ٣ $نها_{س ← ١}$ ه ( س ) = ٣ $نها_{س ← ١}$ ( س + ٥ ) = ٣ × ٦ = ١٨
