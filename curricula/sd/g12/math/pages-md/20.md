لاحظ إن س تؤول إلى أ لا دخل له بالقيمة د (أ) . ففى المثال التمهيدى السابق كان للنهاية قيمة حقيقية تساوى ٧ بينما الدالة نفسها غير معرفة عند س = ٢ .

فهناك حالات تكون فيها د ( أ ) غير معرفة ولكن نها د ( س ) موجودة بينما هنالك حالات فيها د ( أ ) معرفة ولكن $نها_{س ← أ}$ د ( س ) غيــر موجودة أو إن وجدت لاتساوى د ( أ ) . وفي بعض الحالات تكون د ( أ ) موجودة وتســاوى $نها_{س ← أ}$ د ( س ) .

وجود النهاية نها د ( س ) يقتضى أن تساوى عدداً حقيقياً معيناً . أمَّا إذا كانت هذه النهاية لها أكثر من قيمة مختلفة أو كانت أكبر من أى عدد يمكن أن نتصوره فإننا نقول إن النهاية ليس لها وجود . وقد اتفق على كتابتها على النحو التالى :

$نها_{س ← أ}$ د ( س ) = ∞

إذا كانت ليس لها قيمة محدودة

**مثال (١) :**

إذا كان :

د ( س ) = $\begin{cases} س + ١ ، س > ١ \\ ٢ س + ٥ ، س ≤ 1 \end{cases}$

فإن :

$نها_{س ← ١}$ د ( س ) غير موجودة .
