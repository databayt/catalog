**مثال (١) :**

احسب متوسط معدل التغير للدالة ص = د ( س ) = $\sqrt{س – ٢}$ عندما تتغير س من ٣ إلى ٣,٢١ .

**الحل :**

Δ ص = د ( س + Δ س ) – د ( س )

س = ٣ ، Δ س = ٣,٢١ – ٣ = ٠,٢١

∴ Δ ص = د ( ٣,٢١ ) – د ( ٣ ) = $\sqrt{[غير مقروء] – ٢}$ – $\sqrt{٣ – ٢}$

= $\sqrt{١,٢١}$ – $\sqrt{١}$ = ١,١ – ١ = ٠,١

∴ $\frac{Δ ص}{Δ س}$ = $\frac{٠,١}{٠,٢١}$ = $\frac{١٠}{٢١}$ ≈ ٠,٤٧٦

**مثال (٢) :**

تتمدد صفيحة دائرية بالتسخين . احسب متوسط معدل التغير في مساحتها عندما يتغير طول نصف قطرها من ٦ سم إلى ٦,١ سم .

**الحل :**

نفرض أن طول نصف القطر = نق

مساحة الصفيحة م = د ( نق ) = π نق$^٢$

$$\frac{Δ م}{Δ نق} = \frac{د ( ٦,١ ) – د ( ٦ )}{٦,١ – ٦} = \frac{π [ ( ٦,١ )^٢ – ٦^٢ ]}{٠,١}$$

$$= \frac{π ( ٦,١ – ٦ ) ( ٦,١ + ٦ )}{٠,١} = \frac{π × ٠,١ × ١٢,١}{٠,١}$$

$$= ١٢,١ π$$
