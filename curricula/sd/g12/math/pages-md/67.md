**مثال (١) :**

كامل ( جد تكامل ) الدالة ٣ س + ١ .

**الحل :**

∫ ( ٣ س + ١ ) د س = $\frac{٣}{٢}$ س$^٢$ + س + ث

لأن $\frac{د}{د س}$ ( $\frac{٣}{٢}$ س$^٢$ + س + ث ) = ٣ س + ١

الآن لكل ن ≠ –١

$\frac{د}{د س}$ ( س$^{ن+١}$ ) = ( ن + ١ ) س$^ن$

أو $\frac{د}{د س}$ $\left( \frac{س^{ن+١}}{ن + ١} \right)$ = س$^ن$

عليه فإن :

∫ س$^ن$ د س = $\frac{س^{ن+١}}{ن + ١}$ + ث

**مثال (٢) :**

∫ س$^٨$ د س = $\frac{س^{٨+١}}{٨ + ١}$ + ث

= $\frac{س^٩}{٩}$ + ث

∫ ٤ س$^٥$ د س = ٤ × $\frac{١}{٦}$ س$^٦$ + ث

= $\frac{٢}{٣}$ س$^٦$ + ث
