| عدد الطلاب<br>ك | عدد الفصول<br>س | ك × س |
| --------------- | --------------- | ----- |
| ٤٨              | ٤               | ١٩٢   |
| ٥٢              | ٨               | ٤١٦   |
| ٥٤              | ١٢              | ٦٤٨   |
| ٥٨              | ١٨              | ١٠٤٤  |
| ٦٠              | ١٤              | ٠٨٤٠  |
| ٦٢              | ١٠              | ٠٦٢٠  |
| ٦٤              | ٧               | ٤٤٨   |
| ٦٥              | ٤               | ٢٦٠   |
| ٦٨              | ٣               | ٢٠٤   |
|                 | ٨٠              | ٤٦٧٢  |

∴ الوسط الحسابى $\overline{س} = \dfrac{\sum ك\ س}{\sum ك}$

$= \dfrac{٤٦٧٢}{٨٠} = ٥٨,٤$

**مثال (٥) :**

متوسط مصروفات أسرة اليومى ٥٠٠ ديناراً ، جد منصرفات هذه الأسرة خلال شهر اكتوبر .

**الحل :**

لاحظ أن بالقانون $\overline{س} = \dfrac{\sum_{ر\ =\ ١}^{ن} س_ر}{ن}$ ثلاثة كميات مجهولة هى الوسط الحسابى $\overline{س}$ ، مجموع المفــردات $\sum_{ر\ =\ ١}^{ن}$ س$_ر$ وعدد المفردات ن . إذا اعطينا اثنين منها يمكن الحصول على المجهول الثالث :

$\overline{س}$ = ٥٠٠ دينار ، ن = ٣١ يوماً
