**( أ ) الدالة الثابتة ص = أ ( أ ثابت ) :**

ص = د ( س ) = أ

$$\frac{Δ ص}{Δ س} = \frac{د ( س + Δ س ) – د ( س )}{Δ س}$$

$$= \frac{أ – أ}{Δ س} = \frac{٠}{Δ س} = صفر$$

$$∴ \frac{د ص}{د س} = نها_{Δ س → ٠} \frac{Δ ص}{Δ س} = صفر$$

$$∴ \frac{د}{د س} ( أ ) = ٠$$
