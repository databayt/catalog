ضع ع = س + Δ س . إذن ع ← س عندما Δ س ← ٠

$$\frac{د ص}{د س} = نها_{Δ س → ٠} \frac{Δ ص}{Δ س} = نها_{ع → س} \frac{ع^ن – س^ن}{ع – س}$$

$$= ن س^{ن – ١}$$

∴

إذا كان ص = س$^ن$

فإن $\frac{د ص}{د س}$ = ن س$^{ن – ١}$

**( جـ ) الدالة ص = أ د(س) ، أ ثابت :**

$$\frac{Δ ص}{Δ س} = \frac{أ د ( س + Δ س ) – أ د ( س )}{Δ س}$$

$$∴ \frac{Δ ص}{Δ س} = نها_{Δ س → ٠} \frac{أ د ( س + Δ س ) – أ د ( س )}{Δ س}$$

$$= أ نها_{Δ س → ٠} \frac{د ( س + Δ س ) – د ( س )}{Δ س}$$

= أ د′ (س)

أي أن مشتقة حاصل ضرب الثابت في الدالة يساوى حاصل ضرب الثابت في مشتقة الدالة .

فإذا كان ص = أ س$^ن$

فان $\frac{د ص}{د س}$ = أ ن س$^{ن – ١}$

مثلاً : إذا كان ص = ٥س$^٧$ فان

$\frac{د ص}{د س}$ ٣٥ س$^٦$
