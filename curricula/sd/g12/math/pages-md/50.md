بأخذ النهايات عندما Δ س → ٠

نها$_{Δ س → ٠}$ $\frac{Δ ص}{Δ س}$ = نها$_{Δ س → ٠}$ $\frac{Δ ل}{Δ س}$ ± نها$_{Δ س → ٠}$ $\frac{Δ ع}{Δ س}$

∴ $\frac{د\ ص}{د\ س}$ = $\frac{د\ ل}{د\ س}$ ± $\frac{د\ ع}{د\ س}$

أي المشتقة الأولى بمجموع أو فرق الدالتين يساوى مجموع أو فرق مشتقتي الدالتين . ويمكن تعميم ذلك بأن :

المشتقة الأولى للمجموع أو الفرق لأي عدد من الدوال يساوى المجموع أو الفرق لمشتقات تلك الدوال.

**مثال (١) :**

جد $\frac{د}{د\ س}$ ( $س^٥$ – ٤ $س^٢$ + ٢ س + ٤ )

**الحل :**

$\frac{د}{د\ س}$ ( $س^٥$ – ٤ $س^٢$ + ٢ س + ٤ )

= $\frac{د}{د\ س}$ $س^٥$ – $\frac{د}{د\ س}$ ٤ $س^٢$ + $\frac{د}{د\ س}$ ٢ س + $\frac{د}{د\ س}$ ٤

= ٥ $س^٤$ – ٨ س + ٢ + صفر

**( ب ) مشتقة حاصل ضرب الدالتين :**

إذا كانت كل من ل ، ع دالتين في المتغير س وكان ص = ل ع

وتغيرت س الي س + Δ س

فإن ص تتغير إلى ص + Δ ص

و ل تتغير إلى ل + Δ ل

و ع تتغير إلى ع + Δ ع

ويكون : ص + Δ ص = ( ل + Δ ل ) ( ع + Δ ع )

= ل ع + ل Δ ع + ع Δ ل + Δ ل Δ ع
