**مثال (٤) :**

جد :

( أ ) ∫ جا ٧ س د س

(ب) ∫ جا ٢ س جتا س د س

**الحل :**

( أ ) من الجدول :

∫ جا ٧س د س = – ١/٧ جتا ٧ س + ث

(ب) جا ٢ س جتا س ليست مع الصيغ الأساسية ولكن

جا ٢ س جتا س = ١/٢ [ جا ٣ س + جا س ]

إذن : ∫ جا ٢ س جتا س د س = ١/٢ ∫ (جا ٣ س + ١/٢جا س) د س

= ١/٢ ( – ١/٣ جتا ٣س ) + ١/٢ ( – جتا س ) + ث

= – ١/٦ جتا ٣ س – ١/٢ جتا س + ث
