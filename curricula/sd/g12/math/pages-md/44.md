$$\frac{Δ ص}{Δ س} = \frac{د ( س + Δ س ) – د ( س )}{Δ س}$$

$$= \frac{\frac{١}{س + Δ س} – \frac{١}{س}}{Δ س}$$

$$= \frac{س – ( س + Δ س )}{( Δ س ) ( س ) ( س + Δ س )}$$

$$= \frac{– Δ س}{( Δ س ) ( س ) ( س + Δ س )}$$

$$= – \frac{١}{س ( س + Δ س )}$$

$$\frac{د ص}{د س} = نها_{Δ س → ٠} \frac{Δ ص}{Δ س} = نها_{Δ س → ٠} \left( – \frac{١}{س ( س + Δ س )} \right)$$

$$= \frac{– ١}{س^٢}$$
