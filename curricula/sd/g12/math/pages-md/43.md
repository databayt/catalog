وبما أن د ( س ) = س$^٢$

∴ د ( س + Δ س ) = ( س + Δ س )$^٢$

$$∴ د' (س) = نها_{Δ س → ٠} \frac{( س + Δ س )^٢ – س^٢}{Δ س}$$

$$= نها_{Δ س → ٠} \frac{س^٢ + ٢ س Δ س + ( Δ س )^٢ – س^٢}{Δ س}$$

$$= نها_{Δ س → ٠} \frac{٢ س Δ س + ( Δ س )^٢}{Δ س}$$

$$= نها_{Δ س → ٠} \frac{Δ س ( ٢ س + Δ س )}{Δ س}$$

$$= نها_{Δ س → ٠} ( ٢ س + Δ س )$$

وبما أن Δ س ← ٠

∴ د′ ( س ) = ٢ س ، عند س = ٣

∴ د′ ( ٣ ) = ٢ × ٣ = ٦

هندسياً تعنى ان ميل المماس لمنحنى الدالة ص = س$^٢$ عند النقطة ( ٣ ، ٩ ) هو ٦ .

**مثال (٢) :**

إذا كان ص = $\frac{١}{س}$ فجد $\frac{د ص}{د س}$ من المبادئ الأولية .

**الحل :**

ص = $\frac{١}{س}$
