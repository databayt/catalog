**( د ) الدالة ص = جا س :**

ص = د ( س ) = جا س

$$\frac{Δ ص}{Δ س} = \frac{د ( س + Δ س ) – د ( س )}{Δ س}$$

$$= \frac{جا ( س + Δ س ) – جا س}{Δ س}$$

$$= \frac{٢ جتا \frac{٢ س + Δ س}{٢} جا \frac{Δ س}{٢}}{Δ س}$$

$$= جتا ( س + \frac{Δ س}{٢} ) \frac{جا \frac{Δ س}{٢}}{\frac{Δ س}{٢}}$$

$$∴ \frac{د ص}{د س} = نها_{Δ س → ٠} جتا ( س + \frac{Δ س}{٢} ) نها_{Δ س → ٠} \frac{جا \frac{Δ س}{٢}}{\frac{Δ س}{٢}}$$

$$= جتا س × ١ = جتا س$$

لأنه بوضع ع = $\frac{Δ س}{٢}$ فان :

$$نها_{Δ س → ٠} \frac{جا \frac{Δ س}{٢}}{\frac{Δ س}{٢}} = نها_{ع → ٠} \frac{جا ع}{ع} = ١$$
