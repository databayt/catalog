### تمرين ( ١ – ٥ )

(١) أحسب قيمة ما يأتي :

( أ ) $^{١١}ق_{٥}$ (ب) $^{١٢}ق_{٧}$ (ج) $^{٥}ق_{١}$ ( د ) $^{١٨}ق_{١٨}$

(ه) $^{٧}ق_{٠}$

(٢) حل المعادلات :

( أ ) $^{١٠}ق_{٣}$ = $^{١٠}ق_{ر}$ (ب) $^{١٥}ق_{٤}$ = $^{ن}ق_{٤}$

(٣) أثبت أن :

( أ ) ( ن – ر ) $^{ن}ق_{ر}$ = ن $^{ن-١}ق_{ر}$ (ب) $^{ن+١}ق_{ر}$ = $\dfrac{ن + ١}{ن - ر + ١}$ $^{ن}ق_{ر}$

(ج) $^{ن}ق_{ر}$ + $^{ن}ق_{ر-١}$ = $^{ن+١}ق_{ر}$

( د ) $\dfrac{^{ن}ق_{ر + ١}}{^{ن}ق_{ر}}$ = $\dfrac{ن - ر}{ر + ١}$

(٤) بكم طريقة يمكن بها اختيار ٥ كتب من ١٢ كتاب ؟
