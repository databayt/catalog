### تمرين (١ – ١)

مستخدماً مبدأ الاستنتاج الرياضي أثبت ما يلي (∀ ن ∋ ط)

(١) $١^٣ + ٢^٣ + ٣^٣ + .. + ن^٣ = \frac{ن^٢ ( ن + ١ )^٢}{٤}$

(٢) $\frac{١}{١ × ٢} + \frac{١}{٢ × ٣} + \frac{١}{٣ × ٤} + ... + \frac{١}{ن (ن + ١)} = \frac{ن}{ن + ١}$

(٣) $٢^١ + ٢^٢ + ٢^٣ + .... + ٢^ن = ٢^{ن+١} - ٢$

(٤) $\frac{١}{٣} + \frac{١}{٩} + \frac{١}{٢٧} + .... + \frac{١}{٣^ن} = \frac{١}{٢} ( ١ - \frac{١}{٣^ن} )$

(٥) $٢ + ٦ + ١٠ + ......... + ( ٤ ن - ٢ ) = ٢ ن^٢$

(٦) $٢ + ٤ + ٦ + ..... ٢ ن = ن (ن + ١)$

(٧) $١×٢+٢×٣+٣×٤+... + ن (ن+١) = \frac{ن (ن + ١) (ن + ٢)}{٣}$

(٨) $٣+٥+٧+..... + (٢ن + ١ ) = ن^٢ + ٢ ن$

(٩) برهن أن $\frac{٦^ن - ٢^ن}{٤} ∋ ط$

(١٠) $١^٣ + ٣^٣ + ٥^٣ + .... + ( ٢ ن - ١ )^٣ = ن^٢ ( ٢ ن^٢ - ١ )$

### ( ١ – ٢ ) مبدأ العد :

العد من المهارات الأساسية التي يتعلمها الإنسان ويستخدمها في حياته اليومية ، وسنستعرض لبعض أساليب العد التي تقلل كمية العمل في المعالجة العددية للمجموعات التي تحتوي على عدد كبير من العناصر .
