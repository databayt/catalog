$$= \frac{١}{٦} ( ر + ١ ) [ ر ( ٢ ر + ١ ) + ٦ ( ر + ١ ) ]$$

$$= \frac{١}{٦} ( ر + ١ ) [ ٢ ر^٢ + ٧ ر + ٦ ]$$

$$= \frac{١}{٦} ( ر + ١ ) ( ر + ٢ ) ( ٢ ر + ٣ )$$

وهكذا نجد أن :

$$\sum_{ر=١}^{ن+١} ر^٢ = \frac{١}{٦} ( ن + ١ ) (( ن + ١ ) + ١ ) ( ٢ ( ن + ١ ) + ١ )$$

$$= \frac{١}{٦} ( ن + ١ ) ( ن + ٢ ) ( ٢ ن + ٣ )$$

وهذه هي العلاقة التي يطلب برهانها.

**مثال (٤) :**

برهن أنه ∀ ن ∋ ط فان $٥^ن - ٢^ن$ تقبل القسمة على ٣ أي :

$$\frac{٥^ن - ٢^ن}{٣} \; ∋ \; ط$$

**الحل :**

نختبر صحة العلاقة عند ن = ١

$$\frac{٥^١ - ٢^١}{٣} = \frac{٥ - ٢}{٣} = \frac{٣}{٣} = ١ ∋ ط$$

∴ العلاقة صحيحة عند ن = ١
