**مثال (1-5) :** تحضير مركب كلورو – بروبان حلقي (مثال على الهيدروكربونات الحلقية).

```
       CH2                                CH2
      /   \                              /   \
  H2C——CH2   + Cl2 ——ضوء وحرارة——→   CH2 —— CHCl + HCl
```

(بروبان حلقي) &nbsp;&nbsp; (كلور) &nbsp;&nbsp; (كلورو – بروبان حلقي) &nbsp;&nbsp; (كلوريد هيدروجين)

**مثال (1-6) :** تحضير مركب كلورو بنزين (مثال على المركــب الأروماتيــة – العطرية)

```
         CH                                     H
        /  \\                                   C
                                              /   \\
   H – C –  C – H    + Cl2  ——Fe——→     H – C      C – Cl
       |    ||                              |      ||                + HCl
   H – C    C – H                       H – C      C – H
        \\  /                                \\   /
          C                                     C
          H                                     H
```

(بنزين) &nbsp;&nbsp; (كلور) &nbsp;&nbsp; (كلورو بنزين)

**ملاحظة :** مركب البنزين (Benzene) في هذا التفاعــل هــو البنــزين العطــري (الأروماتي) ، وليس بنزين السيارات (Benzene) ، إذ أن الأخير هو خليط مــن عدة مركبات هيدروكربونية مشبعة أهمها الأوكتان ($C_8 H_{18}$).

**ب/ طريقة الإضافة :**

وهي تتم بإضافة هاليد هيدروجين إلى الألكين أو الالكاين المناسب ، حسب المعادلة العامة التالية :

```
                              H    X
   \     /                    |    |
  – C = C –   + H – X ——→   – C  – C –
```
