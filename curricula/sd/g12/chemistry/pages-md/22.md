### الدرس الثاني

### الكحولات Alcohols والإيثرات Ethers

### (1-2) الكحولات :

الكحولات هي مشــتقات هيدروكربونيــة تنــتج عنــدما تحــل مجموعـــة هيدروكسيل (OH–) أو أكثــر محــل ذرة هيــدروجين أو أكثــر فــي المركــب الهيدروكربوني . وتكون تسمية الكحولات بإضافة المقطع (ول) إلى الألكان ويقــرأ (ألكانول).

**أمثلة :**

```
        H                          H
        |                          |
   H – C – OH               H – C – H
        |                          |
        H                          H
    (ميثانول)                   (ميثان)

      H   H                     H   H
      |   |                     |   |
  H – C – C – OH           H – C – C – H
      |   |                     |   |
      H   H                     H   H
     (إيثانول)                  (إيثان)
```

الصيغة الجزيئية العامة للكحولات هي : $C_nH_{2n+1}\,OH$

الصيغة البنائية العامة للكحولات هي : $R - OH$
