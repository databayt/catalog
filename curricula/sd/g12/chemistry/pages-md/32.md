### (1–3–2) الكيتون :

الكيتون : هو مركب عضوي ترتبط فيه زمرة الكاربونيل بذرتي كربون :

```
     O
│    ‖    │
– C – C – C –
│         │
```

أبسط الكيتونات توجد به ثلاث ذرات كربون وهو البروبانون (الاسيتون) ويسمي الكيتون بإضافة المقطع (ون) إلى الألكان ليصبح (ألكانون) .

الصيغة الجزيئية العامة للكيتونات هي :   $CnH_{2n}O$

الصيغة البنائية العامة هي :

```
    O
    ‖
R – C – R
R – CO-R
    O
    ‖
R – C – R
```

(حيث $R^{/} ≠ R$) أو ($R^{/} = R$)
